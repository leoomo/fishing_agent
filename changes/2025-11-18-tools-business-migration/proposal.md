# 迁移旧业务逻辑到新架构 - OpenSpec提案

## 📋 概述

**变更ID**: `tools-business-migration`
**标题**: 迁移旧业务逻辑到新架构，保持架构整洁
**状态**: 🟡 进行中
**优先级**: 高
**影响**: 代码组织、开发效率、可维护性

## 🎯 问题陈述

在之前的tools模块简化重构后，src/tools/目录仍然存在以下问题：

1. **遗留文件散乱**: 12个旧的业务逻辑文件未被整理，破坏了架构整洁性
2. **重复功能**: 基础工具存在多个版本，导致维护困难
3. **迁移不完整**: 核心业务逻辑仍依赖旧文件结构
4. **架构混乱**: 新旧架构并存，缺乏清晰的技术边界
5. **扩展受限**: 新工具添加缺乏统一的指导原则

## 🏗️ 解决方案概述

### 新架构目标

基于现有的basic/fishing分层架构，完成遗留业务逻辑的完全迁移：

- **Basic Tools**: 保持简洁，提供通用基础功能
- **Fishing Business**: 完整迁移所有钓鱼相关业务逻辑
  - **Weather Layer**: 迁移天气查询和预报功能
  - **Advice Layer**: 迁移钓鱼分析、评分和推荐功能
  - **Equipment Layer**: 保持预留，为后续扩展做准备

### 目录结构迁移前后对比

**迁移前（混乱状态）**:
```
src/tools/
├── __init__.py
├── basic_tools.py                     # 重复的基础工具
├── langchain_weather_tools_sync.py    # 核心天气工具（612行）
├── enhanced_weather_tool.py           # 独立天气服务
├── enhanced_fishing_scorer.py          # 钓鱼评分算法
├── fishing_analyzer_sync.py           # 钓鱼分析业务
├── math_tool.py                       # 重复数学工具
├── time_tool.py                       # 重复时间工具
├── search_tool.py                     # 重复搜索工具
├── weather_tool.py                    # 过时天气工具
├── weather_tool_sync.py               # 过时天气工具
└── fishing_analyzer.py                # 异步版本
```

**迁移后（整洁架构）**:
```
src/tools/
├── __init__.py                         # 统一入口
├── basic/                              # 基础工具模块
│   ├── __init__.py                     # 基础工具导出
│   ├── time_utils.py                   # 时间工具
│   ├── math_ops.py                     # 数学工具
│   ├── info_search.py                  # 搜索工具
│   └── sys_utils.py                    # 系统工具
├── fishing/                            # 钓鱼业务模块
│   ├── __init__.py                     # 钓鱼工具导出
│   ├── weather/                        # 天气数据层
│   │   ├── __init__.py                 # 天气工具导出
│   │   ├── weather_tools.py            # LangChain天气工具
│   │   ├── fishing_tools.py            # 钓鱼推荐工具
│   │   └── enhanced_weather_service.py # 增强天气服务
│   ├── advice/                         # 钓鱼分析层
│   │   ├── __init__.py                 # 分析工具导出
│   │   ├── scoring_tools.py            # 钓鱼评分工具
│   │   ├── fishing_scorer.py           # 评分算法
│   │   └── analyzer_service.py         # 分析业务服务
│   └── equipment/                      # 装备推荐层（预留）
│       └── __init__.py                 # 装备工具导出
└── core/                               # 核心基础设施
    └── __init__.py                     # 基础设施导出
```
