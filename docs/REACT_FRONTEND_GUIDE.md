# React 管理前端使用指南

智能钓鱼助手 v5.0.2 React管理界面的完整使用指南。

> 📱 **前端地址**: http://localhost:5173
> 🔗 **API后端**: http://localhost:8000
> 🎯 **版本**: v5.0.2

## 🚀 快速开始

### 1. 启动服务

```bash
# 启动后端API服务（Terminal 1）
uv run uvicorn apps.api.main:app --reload --host 0.0.0.0 --port 8000

# 启动前端开发服务器（Terminal 2）
cd apps/web-admin
npm run dev
```

### 2. 访问系统

打开浏览器访问：http://localhost:5173

### 3. 登录系统

使用管理员账号登录：
- 用户名：`admin`
- 密码：`admin123`

## 📊 功能模块详解

### 1. 仪表盘 (Dashboard)

访问路径：`/` 或 `/dashboard`

**功能概览**：
- 📈 **系统概览**: 显示装备总数、用户数、今日活跃等关键指标
- 📊 **实时数据**: API调用量、LLM使用量等实时统计
- 🎯 **快捷操作**: 常用功能的快速入口
- 📋 **最新动态**: 系统最新活动和通知

**使用说明**：
1. 登录后默认进入仪表盘
2. 点击各个卡片可快速跳转到对应功能模块
3. 实时数据每5秒自动更新

### 2. 装备管理 (Equipment Management)

访问路径：`/equipment`

**核心功能**：
- ✅ **装备列表**: 展示所有17条装备数据
- 🔍 **智能搜索**: 支持按名称、品牌、价格区间搜索
- 📂 **分类筛选**: 按鱼竿、渔轮、鱼线、鱼饵等分类
- 📝 **装备编辑**: 添加、修改、删除装备
- 📊 **数据统计**: 实时显示各类装备数量

**操作指南**：

#### 查看装备列表
1. 进入装备管理页面
2. 系统自动加载所有装备数据
3. 使用顶部搜索框快速查找装备
4. 使用分类标签筛选特定类型装备

#### 搜索装备
```
搜索示例：
- 按名称：搜索 "禧玛诺" 查看所有禧玛诺品牌装备
- 按品牌：搜索 "达亿瓦" 查看达亿瓦产品
- 按价格：使用价格区间筛选器
- 按类别：点击分类标签（鱼竿、渔轮等）
```

#### 添加新装备
1. 点击"添加装备"按钮
2. 填写装备信息：
   - 装备名称
   - 品牌
   - 类别
   - 价格
   - 规格
   - 描述
3. 点击"保存"完成添加

#### 编辑装备
1. 在装备列表中找到要编辑的装备
2. 点击操作列的"编辑"按钮
3. 修改装备信息
4. 点击"保存"提交更改

#### 删除装备
1. 选择要删除的装备
2. 点击"删除"按钮
3. 在确认对话框中点击"确定"

### 3. 数据分析 (Analytics)

访问路径：`/analytics`

**分析维度**：
- 📊 **装备统计**: 总量、分类、价格分布
- 📈 **趋势分析**: 月度增长趋势（1-36个月）
- 🏆 **品牌排行**: Top N品牌市场份额
- 👥 **用户行为**: 活跃度、购买行为分析
- 📋 **报表导出**: PDF/Excel格式导出

**使用指南**：

#### 查看装备统计
1. 进入数据分析页面
2. 选择"装备统计"标签
3. 查看各类图表：
   - 装备总量饼图
   - 分类分布柱状图
   - 价格分布直方图

#### 分析增长趋势
1. 选择"趋势分析"标签
2. 设置时间范围（1-36个月）
3. 查看折线图展示的装备增长趋势
4. 可按类别筛选查看特定类型趋势

#### 品牌排行榜
1. 选择"品牌排行"标签
2. 设置Top N数量（默认10）
3. 查看品牌装备数量和市场占有率
4. 支持按类别筛选

#### 生成报表
1. 点击"生成报表"按钮
2. 选择报表类型：
   - 装备报表
   - 用户报表
   - 综合业务报表
3. 选择导出格式（PDF/Excel）
4. 设置筛选条件
5. 点击"生成并下载"

### 4. 系统配置 (Configuration)

访问路径：`/config`

**配置类型**：
- 🔑 **API密钥**: 各平台API密钥管理
- ⚙️ **系统参数**: 系统运行参数配置
- 🤖 **Agent配置**: Agent行为参数
- 📊 **算法配置**: 评分算法参数

**操作指南**：

#### API密钥管理
1. 进入系统配置页面
2. 筛选"api"类型配置
3. 查看已配置的API密钥（已加密显示）
4. 点击"测试"验证密钥有效性

#### 添加新配置
1. 点击"添加配置"按钮
2. 填写配置信息：
   - 配置键名（英文）
   - 配置值
   - 配置类型
   - 描述
   - 是否加密（API密钥建议加密）
3. 点击"保存"

#### 编辑配置
1. 找到要修改的配置
2. 点击"编辑"按钮
3. 修改配置值或描述
4. 点击"更新"保存更改

#### 测试API密钥
1. 在API密钥列表中
2. 点击"测试"按钮
3. 系统会自动验证密钥有效性
4. 显示测试结果（成功/失败）

### 5. 爬虫管理 (Crawler Management)

访问路径：`/crawler`

**功能特性**：
- 🕷️ **多平台支持**: 淘宝、京东、钓鱼论坛
- 📋 **任务列表**: 查看所有爬虫任务
- ▶️ **手动触发**: 立即执行爬虫任务
- 📊 **进度监控**: 实时查看爬虫进度
- 🔄 **数据同步**: 查看同步状态

**操作指南**：

#### 查看任务列表
1. 进入爬虫管理页面
2. 查看所有爬虫任务
3. 显示任务状态：
   - 等待中
   - 运行中
   - 已完成
   - 失败

#### 手动触发爬虫
1. 点击"触发任务"按钮
2. 选择爬虫类型：
   - 淘宝爬虫
   - 京东爬虫
   - 论坛爬虫
3. 输入搜索关键词
4. 设置爬取页数
5. 点击"开始爬取"

#### 查看爬虫进度
1. 任务运行时会显示实时进度
2. 包括：
   - 已爬取页面数
   - 总页面数
   - 获取装备数
   - 预计剩余时间

#### 重试失败任务
1. 在任务列表中找到失败的任务
2. 点击"重试"按钮
3. 系统会重新执行该任务

### 6. 系统监控 (Monitor)

访问路径：`/monitor`

**监控指标**：
- 📊 **API统计**: 调用量、响应时间、错误率
- 🤖 **LLM统计**: Token消耗、成本、成功率
- 💾 **数据库**: 查询时间、慢查询、连接池
- ✅ **健康检查**: 服务状态检查

**实时监控**：
- 数据每5秒自动更新
- 使用WebSocket实时推送
- 支持自定义监控面板

## 🛠️ 故障排除

### 常见问题

#### 1. 无法登录
- 检查后端服务是否启动（http://localhost:8000）
- 验证用户名密码是否正确
- 查看浏览器控制台错误信息

#### 2. 数据加载失败
- 检查网络连接
- 验证API服务是否正常
- 查看API响应状态

#### 3. 权限不足
- 确认登录状态
- 检查用户角色
- 联系管理员分配权限

### 调试方法

#### 1. 浏览器开发者工具

Network 标签

Console 标签

  .then(data => console.log(data))
