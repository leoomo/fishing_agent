## 概述

本文档定义鱼类知识库的数据库表结构，用于存储路亚对象鱼的生态习性、钓法技巧等知识内容。

---

## 表结构设计

### 1. fish_species（鱼类基础表）

**用途**：存储鱼类的基础信息和生态特征

```sql
CREATE TABLE fish_species (
    -- 主键
    id INTEGER PRIMARY KEY AUTOINCREMENT,

    -- 基本信息
    name_cn TEXT NOT NULL UNIQUE,           -- 中文名：鲈鱼
    name_en TEXT,                           -- 英文名：Largemouth Bass
    name_latin TEXT,                        -- 学名：Micropterus salmoides
    aliases TEXT,                           -- 别名JSON：["黑鲈", "大嘴鲈", "加州鲈"]

    -- 分类信息
    category TEXT NOT NULL,                 -- 淡水/海水/广盐
    family TEXT,                            -- 科：太阳鱼科
    order_name TEXT,                        -- 目：鲈形目

    -- 生态习性
    habitat TEXT,                           -- 栖息水层：中上层/底层/全水层
    habitat_description TEXT,               -- 栖息环境描述
    active_temp_min REAL,                   -- 活跃温度下限（℃）
    active_temp_max REAL,                   -- 活跃温度上限（℃）
    optimal_temp_min REAL,                  -- 最佳温度下限（℃）
    optimal_temp_max REAL,                  -- 最佳温度上限（℃）
    active_seasons TEXT,                    -- 活跃季节JSON：["春", "夏", "秋"]
    feeding_habits TEXT,                    -- 食性：肉食/杂食/滤食
    prey_types TEXT,                        -- 主要猎物JSON：["小鱼", "虾", "蛙"]

    -- 体型特征
    max_length REAL,                        -- 最大体长（cm）
    common_length_min REAL,                 -- 常见体长下限（cm）
    common_length_max REAL,                 -- 常见体长上限（cm）
    max_weight REAL,                        -- 最大体重（kg）
    common_weight_min REAL,                 -- 常见体重下限（kg）
    common_weight_max REAL,                 -- 常见体重上限（kg）

    -- 路亚相关
    lure_difficulty TEXT,                   -- 路亚难度：新手/进阶/高手
    fight_intensity TEXT,                   -- 搏鱼强度：温和/中等/激烈
    recommended_lures TEXT,                 -- 推荐拟饵类型JSON
    recommended_rigs TEXT,                  -- 推荐钓组JSON
    recommended_rod_power TEXT,             -- 推荐竿硬度JSON：["ML", "M", "MH"]
    recommended_line_lb_min REAL,           -- 推荐线号下限（lb）
    recommended_line_lb_max REAL,           -- 推荐线号上限（lb）

    -- 分布信息
    native_region TEXT,                     -- 原产地
    distribution_cn TEXT,                   -- 中国分布区域
    introduced_status TEXT,                 -- 引入状态：原生/引入/入侵

    -- 法规相关
    is_protected INTEGER DEFAULT 0,         -- 是否保护物种
    fishing_regulations TEXT,               -- 钓捕规定

    -- 审计字段
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_fish_name_cn ON fish_species(name_cn);
CREATE INDEX idx_fish_category ON fish_species(category);
CREATE INDEX idx_fish_difficulty ON fish_species(lure_difficulty);
```

### 2. fish_knowledge（鱼类知识条目表）

**用途**：存储关于鱼类的详细知识内容，支持向量化搜索

```sql
CREATE TABLE fish_knowledge (
    -- 主键
    id INTEGER PRIMARY KEY AUTOINCREMENT,

    -- 关联鱼类（可为NULL表示通用知识）
    fish_species_id INTEGER,

    -- 知识分类
    knowledge_type TEXT NOT NULL,           -- 知识类型
    title TEXT NOT NULL,                    -- 标题
    content TEXT NOT NULL,                  -- 内容（Markdown格式）
    summary TEXT,                           -- 摘要（用于快速展示）

    -- 标签和关键词
    tags TEXT,                              -- 标签JSON：["春季", "水草区", "晨钓"]
    keywords TEXT,                          -- 关键词（用于搜索）

    -- 向量化相关
    embedding_id TEXT,                      -- Chroma向量ID
    is_vectorized INTEGER DEFAULT 0,        -- 是否已向量化

    -- 来源和权威性
    source TEXT,                            -- 知识来源
    author TEXT,                            -- 作者/编辑
    reliability_score REAL DEFAULT 0.8,     -- 可靠性评分（0-1）

    -- 审计字段
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 外键约束
    FOREIGN KEY (fish_species_id) REFERENCES fish_species(id) ON DELETE CASCADE
);

-- 索引
CREATE INDEX idx_knowledge_fish ON fish_knowledge(fish_species_id);
CREATE INDEX idx_knowledge_type ON fish_knowledge(knowledge_type);
CREATE INDEX idx_knowledge_vectorized ON fish_knowledge(is_vectorized);
CREATE INDEX idx_knowledge_tags ON fish_knowledge(tags);
```

### 3. knowledge_type 枚举值

| knowledge_type | 说明 | 示例内容 |
|----------------|------|---------|
| `behavior` | 习性行为 | 鲈鱼的捕食行为、活动规律 |
| `habitat` | 栖息环境 | 翘嘴喜欢的水域类型 |
| `season` | 季节特性 | 春季鲈鱼的产卵行为 |
| `technique` | 钓法技巧 | 钓鲈鱼的操竿手法 |
| `lure_match` | 拟饵匹配 | 适合钓鲈鱼的拟饵类型 |
| `rig_match` | 钓组匹配 | 钓鲈鱼常用的钓组 |
| `location` | 钓点选择 | 如何找鲈鱼的标点 |
| `time` | 时间规律 | 鲈鱼一天中的活跃时段 |
| `weather` | 天气影响 | 气压变化对鲈鱼的影响 |
| `identification` | 识别特征 | 如何区分大嘴鲈和小嘴鲈 |

### 4. fish_season_activity（鱼类季节活动表）

**用途**：详细记录不同鱼类在不同季节的活动规律

```sql
CREATE TABLE fish_season_activity (
    -- 主键
    id INTEGER PRIMARY KEY AUTOINCREMENT,

    -- 关联鱼类
    fish_species_id INTEGER NOT NULL,

    -- 季节信息
    season TEXT NOT NULL,                   -- 春/夏/秋/冬
    month_start INTEGER,                    -- 起始月份
    month_end INTEGER,                      -- 结束月份

    -- 活动特征
    activity_level TEXT,                    -- 活跃度：低/中/高/极高
    water_layer TEXT,                       -- 主要活动水层
    preferred_structure TEXT,               -- 偏好结构物JSON
    feeding_intensity TEXT,                 -- 觅食强度：低/中/高

    -- 路亚建议
    best_time_of_day TEXT,                  -- 最佳时段JSON：["早晨", "傍晚"]
    recommended_lures TEXT,                 -- 该季节推荐拟饵JSON
    recommended_retrieve TEXT,              -- 收线方式JSON
    key_tips TEXT,                          -- 关键技巧

    -- 审计字段
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 外键约束
    FOREIGN KEY (fish_species_id) REFERENCES fish_species(id) ON DELETE CASCADE
);

-- 索引
CREATE INDEX idx_activity_fish ON fish_season_activity(fish_species_id);
CREATE INDEX idx_activity_season ON fish_season_activity(season);
```

## FishKnowledge 业务类设计

```python
from typing import List, Optional, Dict, Any
from dataclasses import dataclass


@dataclass
class FishInfo:
    """鱼类基础信息"""
    id: int
    name_cn: str
    name_en: Optional[str]
    category: str
    habitat: str
    lure_difficulty: str
    recommended_lures: List[str]
    recommended_rigs: List[str]
    aliases: List[str]


@dataclass
class KnowledgeItem:
    """知识条目"""
    id: int
    knowledge_type: str
    title: str
    content: str
    summary: Optional[str]
    tags: List[str]
    fish_species_id: Optional[int]


class FishKnowledgeService:
    """鱼类知识服务"""

    def __init__(self, db, image_manager, vector_store=None):
        self.db = db
        self.image_manager = image_manager
        self.vector_store = vector_store

    # ========== 鱼类查询 ==========

    def get_fish_by_name(self, name: str) -> Optional[FishInfo]:
        """根据名称查询鱼类（支持别名）"""
        query = """
            SELECT * FROM fish_species
            WHERE name_cn = ?
               OR name_en = ?
               OR aliases LIKE ?
        """
        rows = self.db.execute(query, (name, name, f'%"{name}"%'))

        if rows:
            return self._row_to_fish_info(rows[0])
        return None

    def search_fish(
        self,
        category: Optional[str] = None,
        difficulty: Optional[str] = None,
        habitat: Optional[str] = None
    ) -> List[FishInfo]:
        """搜索鱼类"""
        query = "SELECT * FROM fish_species WHERE 1=1"
        params = []

        if category:
            query += " AND category = ?"
            params.append(category)
        if difficulty:
            query += " AND lure_difficulty = ?"
            params.append(difficulty)
        if habitat:
            query += " AND habitat LIKE ?"
            params.append(f"%{habitat}%")

        rows = self.db.execute(query, tuple(params))
        return [self._row_to_fish_info(row) for row in rows]

    def get_fish_with_images(self, fish_id: int) -> Dict[str, Any]:
        """获取鱼类完整信息（含图片）"""
        fish = self.get_fish_by_id(fish_id)
        if not fish:
            return None

        images = self.image_manager.get_fish_images(fish_id)

        return {
            "fish": fish,
            "images": images,
            "main_image": next((img for img in images if img.image_type == 'main'), None)
        }

    # ========== 知识查询 ==========

    def get_knowledge_by_fish(
        self,
        fish_id: int,
        knowledge_type: Optional[str] = None
    ) -> List[KnowledgeItem]:
        """获取特定鱼类的知识"""
        query = """
            SELECT * FROM fish_knowledge
            WHERE fish_species_id = ?
        """
        params = [fish_id]

        if knowledge_type:
            query += " AND knowledge_type = ?"
            params.append(knowledge_type)

        query += " ORDER BY knowledge_type, id"

        rows = self.db.execute(query, tuple(params))
        return [self._row_to_knowledge(row) for row in rows]

    def get_general_knowledge(
        self,
        knowledge_type: Optional[str] = None
    ) -> List[KnowledgeItem]:
        """获取通用知识（不关联特定鱼类）"""
        query = """
            SELECT * FROM fish_knowledge
            WHERE fish_species_id IS NULL
        """
        params = []

        if knowledge_type:
            query += " AND knowledge_type = ?"
            params.append(knowledge_type)

        rows = self.db.execute(query, tuple(params))
        return [self._row_to_knowledge(row) for row in rows]

    def search_knowledge(self, keyword: str) -> List[KnowledgeItem]:
        """关键词搜索知识"""
        query = """
            SELECT * FROM fish_knowledge
            WHERE title LIKE ?
               OR content LIKE ?
               OR keywords LIKE ?
               OR tags LIKE ?
        """
        pattern = f"%{keyword}%"
        rows = self.db.execute(query, (pattern, pattern, pattern, pattern))
        return [self._row_to_knowledge(row) for row in rows]

    def semantic_search(self, query_text: str, top_k: int = 5) -> List[KnowledgeItem]:
        """语义搜索知识（需要向量库支持）"""
        if not self.vector_store:
            # 降级为关键词搜索
            return self.search_knowledge(query_text)

        # 向量搜索
        results = self.vector_store.search(
            collection="fish_knowledge",
            query_text=query_text,
            top_k=top_k
        )

        # 根据ID查询完整内容
        knowledge_ids = [r['id'] for r in results]
        return self.get_knowledge_by_ids(knowledge_ids)

    # ========== 季节活动查询 ==========

    def get_season_activity(
        self,
        fish_id: int,
        season: Optional[str] = None
    ) -> List[Dict[str, Any]]:
        """获取鱼类的季节活动信息"""
        query = """
            SELECT * FROM fish_season_activity
            WHERE fish_species_id = ?
        """
        params = [fish_id]

        if season:
            query += " AND season = ?"
            params.append(season)

        return self.db.execute(query, tuple(params))

    # ========== 推荐查询 ==========

    def get_lure_recommendations(self, fish_id: int) -> Dict[str, Any]:
        """获取针对特定鱼种的拟饵推荐"""
        fish = self.get_fish_by_id(fish_id)
        if not fish:
            return None

        return {
            "fish": fish.name_cn,
            "difficulty": fish.lure_difficulty,
            "recommended_lures": fish.recommended_lures,
            "recommended_rigs": fish.recommended_rigs,
            "rod_power": self._get_rod_power(fish_id),
            "line_spec": self._get_line_spec(fish_id)
        }

    # ========== 私有方法 ==========

    def _row_to_fish_info(self, row: Dict) -> FishInfo:
        import json
        return FishInfo(
            id=row['id'],
            name_cn=row['name_cn'],
            name_en=row.get('name_en'),
            category=row['category'],
            habitat=row.get('habitat', ''),
            lure_difficulty=row.get('lure_difficulty', ''),
            recommended_lures=json.loads(row.get('recommended_lures', '[]')),
            recommended_rigs=json.loads(row.get('recommended_rigs', '[]')),
            aliases=json.loads(row.get('aliases', '[]'))
        )

    def _row_to_knowledge(self, row: Dict) -> KnowledgeItem:
        import json
        return KnowledgeItem(
            id=row['id'],
            knowledge_type=row['knowledge_type'],
            title=row['title'],
            content=row['content'],
            summary=row.get('summary'),
            tags=json.loads(row.get('tags', '[]')),
            fish_species_id=row.get('fish_species_id')
        )
```

def format_fish_info(fish_info: Dict[str, Any]) -> str:
    """格式化鱼类信息"""
    fish = fish_info['fish']
    main_image = fish_info.get('main_image')

    output = f"# {fish.name_cn}"
    if fish.name_en:
        output += f" ({fish.name_en})"
    output += "\n\n"

    if main_image:
        output += f"![{fish.name_cn}]({main_image.image_url})\n\n"

    output += f"**分类**: {fish.category}\n"
    output += f"**栖息水层**: {fish.habitat}\n"
    output += f"**路亚难度**: {fish.lure_difficulty}\n\n"

    output += "## 推荐拟饵\n"
    for lure in fish.recommended_lures:
        output += f"- {lure}\n"

    output += "\n## 推荐钓组\n"
    for rig in fish.recommended_rigs:
        output += f"- {rig}\n"

    return output
```

def format_knowledge(knowledge: KnowledgeItem, images: List = None) -> str:
    """格式化知识内容"""
    output = f"# {knowledge.title}\n\n"

    if knowledge.tags:
        output += "**标签**: " + " | ".join(knowledge.tags) + "\n\n"

    output += knowledge.content + "\n"

    if images:
        output += "\n## 相关图解\n\n"
        for img in images:
            output += f"![{img.description or '图解'}]({img.image_url})\n\n"

    return output
```
