## 📊 表结构概览

导环相关表共3个：

1. **guide_specs**（导环规格表）- 核心表
2. **rod_guide_kits**（导环套装表）- 套装管理
3. **rod_guide_kit_items**（导环套装组成表）- 套装明细

---

## 🗄️ guide_specs（导环规格表）

### 表结构

导环作为独立配件的详细规格表。

```sql
CREATE TABLE guide_specs (
    equipment_id TEXT PRIMARY KEY,          -- 关联equipment.id
    guide_type TEXT NOT NULL CHECK(guide_type IN ('tip', 'tip_top', 'running', 'stripper', 'launcher')),
    frame_type TEXT NOT NULL CHECK(frame_type IN ('单脚', '双脚', '无脚', '三脚')),
    ring_material TEXT CHECK(ring_material IN ('SIC', '钛合金', '陶瓷', '不锈钢', 'Torzite')),
    frame_material TEXT CHECK(frame_material IN ('钛合金', '不锈钢', '铝合金', '碳纤维')),
    guide_size REAL CHECK(guide_size > 0),  -- 导环尺寸 (mm)
    weight REAL CHECK(weight >= 0),         -- 单个重量 (g)
    ring_inner_diameter REAL CHECK(ring_inner_diameter > 0),  -- 环体内径 (mm)
    ring_outer_diameter REAL CHECK(ring_outer_diameter >= ring_inner_diameter),  -- 环体外径 (mm)
    frame_thickness REAL CHECK(frame_thickness > 0),  -- 支架厚度 (mm)
    surface_treatment TEXT,                 -- 表面处理
    smoothness_score REAL CHECK(smoothness_score BETWEEN 1 AND 10),  -- 顺滑度评分
    friction_coefficient REAL CHECK(friction_coefficient >= 0),  -- 摩擦系数
    casting_boost REAL CHECK(casting_boost >= 0),  -- 抛投提升率 (%)
    salt_water_resistance TEXT CHECK(salt_water_resistance IN ('优秀', '良好', '一般', '差')),
    compatible_line_types TEXT,             -- 兼容线组类型 (JSON): '["PE线", "尼龙线"]'
    compatible_line_diameter TEXT,          -- 适配线径范围: "0.8-2.0号"
    smart_features BOOLEAN DEFAULT FALSE,   -- 智能功能
    sensor_types TEXT,                      -- 传感器类型 (JSON)

    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE
);
```

### 索引设计

```sql
CREATE INDEX idx_guide_type ON guide_specs(guide_type);
CREATE INDEX idx_ring_material ON guide_specs(ring_material);
CREATE INDEX idx_frame_type ON guide_specs(frame_type);
CREATE INDEX idx_guide_size ON guide_specs(guide_size);
CREATE INDEX idx_guide_type_material ON guide_specs(guide_type, ring_material); -- 复合索引
```

## 📖 字段详解

### 导环类型

| 字段值 | 中文名称 | 位置 | 说明 |
|--------|---------|------|------|
| **tip** | 竿稍导环 | 最前端 | 最小的导环 |
| **tip_top** | 竿稍顶导环 | 第2位 | 次小导环 |
| **running** | 中继导环 | 中间段 | 标准尺寸导环 |
| **stripper** | 卸力导环 | 靠近手柄 | 最大的导环 |
| **launcher** | 发射导环 | 特殊用途 | 抛投专用 |

### 支架类型

| 类型 | 说明 | 特点 |
|------|------|------|
| **单脚** | 单边支撑 | 轻量化，适合竿稍 |
| **双脚** | 双边支撑 | 稳定性好，适合中继 |
| **无脚** | 直接卡扣 | 快速更换 |
| **三脚** | 三点支撑 | 超稳定，适合海钓 |

### 环体材质

| 材质 | 特点 | 适用场景 |
|------|------|---------|
| **SIC** | 硬度高、耐磨 | 主流选择，性价比高 |
| **钛合金** | 轻量、防腐 | 高端路亚竿 |
| **陶瓷** | 顺滑、耐用 | 台钓竿 |
| **不锈钢** | 经济实用 | 入门级装备 |
| **Torzite** | 顶级材质 | 专业竞技 |

## 🗄️ rod_guide_kits（导环套装表）

### 表结构

预配置的导环套装，支持组合销售。

```sql
CREATE TABLE rod_guide_kits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    kit_name TEXT NOT NULL,                -- 套装名称
    kit_code TEXT UNIQUE NOT NULL,         -- 套装编码
    brand_id INTEGER,                      -- 关联brands.id
    description TEXT,                      -- 套装描述
    total_guides INTEGER NOT NULL CHECK(total_guides > 0), -- 导环总数
    applicable_rod_types TEXT,             -- 适用鱼竿类型 (JSON): '["路亚竿", "海竿"]'
    kit_price REAL CHECK(kit_price >= 0),  -- 套装价格
    individual_total_price REAL CHECK(individual_total_price >= kit_price), -- 原价
    savings_amount REAL CHECK(savings_amount >= 0), -- 节省金额
    savings_percentage REAL CHECK(savings_percentage BETWEEN 0 AND 100), -- 节省百分比
    is_active BOOLEAN DEFAULT TRUE,        -- 是否启用
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (brand_id) REFERENCES brands(id) ON DELETE SET NULL
);
```

### 索引设计

```sql
CREATE INDEX idx_kit_code ON rod_guide_kits(kit_code);
CREATE INDEX idx_kit_brand ON rod_guide_kits(brand_id);
CREATE INDEX idx_kit_active ON rod_guide_kits(is_active);
```

## 🗄️ rod_guide_kit_items（导环套装组成表）

### 表结构

导环套装的具体组成明细。

```sql
CREATE TABLE rod_guide_kit_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    kit_id INTEGER NOT NULL,                -- 关联rod_guide_kits.id
    guide_equipment_id TEXT NOT NULL,       -- 关联导环equipment.id
    quantity INTEGER DEFAULT 1 CHECK(quantity > 0), -- 数量
    position_index INTEGER CHECK(position_index > 0), -- 推荐安装位置索引
    position_name TEXT,                     -- 位置名称
    sort_order INTEGER DEFAULT 0,          -- 排序
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (kit_id) REFERENCES rod_guide_kits(id) ON DELETE CASCADE,
    FOREIGN KEY (guide_equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    UNIQUE (kit_id, guide_equipment_id, position_index)
);
```

### 索引设计

```sql
CREATE INDEX idx_kit_items_kit ON rod_guide_kit_items(kit_id);
CREATE INDEX idx_kit_items_guide ON rod_guide_kit_items(guide_equipment_id);
```

## 📈 查询示例

### 1. 按类型和材质查询导环

```python
def search_guides(
    self,
    guide_type: Optional[str] = None,
    ring_material: Optional[str] = None,
    size_min: Optional[float] = None,
    size_max: Optional[float] = None,
    smart_features: Optional[bool] = None,
    limit: int = 20
):
    """查询导环产品"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, gs.*
        FROM equipment e
        JOIN guide_specs gs ON e.id = gs.equipment_id
        WHERE e.category = '导环'
    '''
    params = []

    if guide_type:
        query += ' AND gs.guide_type = ?'
        params.append(guide_type)

    if ring_material:
        query += ' AND gs.ring_material = ?'
        params.append(ring_material)

    if size_min and size_max:
        query += ' AND gs.guide_size BETWEEN ? AND ?'
        params.extend([size_min, size_max])

    if smart_features is not None:
        query += ' AND gs.smart_features = ?'
        params.append(smart_features)

    query += ' ORDER BY e.confidence DESC, gs.smoothness_score DESC LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

### 2. 查询导环套装

```python
def get_guide_kits(self, applicable_rod_type: str = None, brand_id: int = None):
    """查询导环套装（含明细）"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT
            rgk.*,
            b.brand_name,
            rgki.guide_equipment_id,
            rgki.quantity,
            rgki.position_index,
            rgki.position_name,
            e.name as guide_name,
            gs.guide_size,
            gs.ring_material
        FROM rod_guide_kits rgk
        LEFT JOIN brands b ON rgk.brand_id = b.id
        LEFT JOIN rod_guide_kit_items rgki ON rgk.id = rgki.kit_id
        LEFT JOIN equipment e ON rgki.guide_equipment_id = e.id
        LEFT JOIN guide_specs gs ON rgki.guide_equipment_id = gs.equipment_id
        WHERE rgk.is_active = 1
    '''
    params = []

    if brand_id:
        query += ' AND rgk.brand_id = ?'
        params.append(brand_id)

    query += ' ORDER BY rgk.savings_percentage DESC'

    cursor.execute(query, params)

    # 组装套装数据
    results = {}
    for row in cursor.fetchall():
        kit_id = row['id']
        if kit_id not in results:
            results[kit_id] = {
                'kit_info': {k: v for k, v in dict(row).items()
                           if not k.startswith(('guide_', 'position_', 'quantity'))},
                'guides': []
            }
        results[kit_id]['guides'].append({
            'position_index': row['position_index'],
            'position_name': row['position_name'],
            'quantity': row['quantity'],
            'guide_name': row['guide_name'],
            'guide_size': row['guide_size'],
            'ring_material': row['ring_material']
        })

    return list(results.values())
```
