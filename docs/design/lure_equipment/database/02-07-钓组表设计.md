## 1. 设计概述

### 1.1 设计目标

钓组表用于管理路亚钓组的完整体系，支持：

- **完整钓组体系**：21种路亚钓组的详细信息
- **配件组成关系**：钓组与配件的组成关系
- **场景匹配**：钓组与水域、鱼种、季节的匹配
- **竿-钓组适配**：钓组与鱼竿的适配关系

### 1.2 钓组分类体系

根据 `fishing_tools_knowledge.md` 知识库，路亚钓组共21种：

```
路亚钓组体系
├── 经典软饵钓组 (8种)
│   ├── 德州钓组 (Texas Rig)
│   ├── 无铅德州钓组 (Weightless Texas Rig)
│   ├── 卡罗莱纳钓组 (Carolina Rig)
│   ├── 维基钓组 (Wacky Rig)
│   ├── 倒吊钓组 (Down Shot)
│   ├── 咬铅钓组 (Split Shot)
│   ├── Neko钓组 (Neko Rig)
│   └── 自由钓组 (Free Rig)
├── 铅头钩钓组 (4种)
│   ├── 铅头钩钓组 (Jig Head)
│   ├── 球形铅头钩 (Ball Style Rig)
│   ├── 尖形铅头钩 (Barter Style Rig)
│   └── 足球形铅头钩 (Football Style Jigheads)
├── 多钩钓组 (3种)
│   ├── 三向钓组 (3 Way Swivel Rig)
│   ├── 双钩底钓组 (Double Hook Bottom Rig)
│   └── 双钩倒挂式钓组 (Double Hook Drop Shot Rig)

│   ├── 浮漂钓组 (Bobbers or Floats Rig)
```

## 2. 钓组类型字典表 (rig_types)

### 2.1 表结构（扩展版）

```sql
CREATE TABLE rig_types (
    id TEXT PRIMARY KEY,               -- 类型ID: 'texas', 'carolina', 'drop_shot'
    name_cn TEXT NOT NULL,             -- 中文名: '德州钓组', '卡罗莱纳钓组'
    name_en TEXT,                      -- 英文名: 'Texas Rig', 'Carolina Rig'
    category TEXT NOT NULL CHECK(category IN (
        '经典软饵钓组', '铅头钩钓组', '多钩钓组', '浮漂钓组', '特殊钓组'
    )),
    description TEXT,                  -- 钓组描述
    composition_summary TEXT,          -- 组成摘要: '母线 + 子弹铅 + 曲柄钩 + 软饵'
    suitable_lure_types TEXT,          -- 适合的饵类型（JSON数组）: '["t_tail", "craw"]'
    typical_scenario TEXT,             -- 典型使用场景
    difficulty_level TEXT CHECK(difficulty_level IN ('入门', '进阶', '高级')),

    -- ═══════════════════════════════════════════════════════════
    -- 🆕 扩展字段（v1.0新增）
    -- ═══════════════════════════════════════════════════════════
    water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')),
    target_fish_types TEXT,            -- 目标鱼种（JSON）: '["黑鲈", "翘嘴"]'
    advantages TEXT,                   -- 钓组优势
    disadvantages TEXT,                -- 钓组劣势
    trend_2025 TEXT,                   -- 2025年新趋势

    icon_url TEXT,
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **id** | TEXT | 唯一标识 | `texas`, `carolina`, `drop_shot` |
| **name_cn** | TEXT | 中文名称 | `德州钓组`, `卡罗莱纳钓组` |
| **name_en** | TEXT | 英文名称 | `Texas Rig`, `Carolina Rig` |
| **category** | TEXT | 所属分类 | `经典软饵钓组`, `铅头钩钓组` |
| **composition_summary** | TEXT | 组成摘要 | `母线 + 子弹铅 + 曲柄钩 + 软饵` |
| **suitable_lure_types** | TEXT | 适合饵类型（JSON） | `["t_tail", "craw", "stick_worm"]` |
| **difficulty_level** | TEXT | 难度等级 | `入门`, `进阶`, `高级` |
| **water_type** | TEXT | 水域类型 | `淡水`, `海水`, `通用` |
| **advantages** | TEXT | 钓组优势 | `重心稳定、平衡度佳、泳形自然` |

## 3. 钓组规格表 (rig_specs)

### 3.1 表结构

钓组的**详细规格**表，包含组装步骤、操作技巧等。

```sql
CREATE TABLE rig_specs (
    rig_type_id TEXT PRIMARY KEY,      -- 关联rig_types.id

    -- ═══════════════════════════════════════════════════════════
    -- 📋 钓组组成详情
    -- ═══════════════════════════════════════════════════════════
    main_line_type TEXT,               -- 主线类型: 'PE线', '尼龙线'
    main_line_spec TEXT,               -- 主线规格: '0.8#-2.0#'
    leader_line_type TEXT,             -- 前导线类型: '碳线'
    leader_line_spec TEXT,             -- 前导线规格: '0.6#-1.5#'
    leader_length_cm TEXT,             -- 前导线长度: '30-50cm'

    hook_type TEXT,                    -- 钩类型: '曲柄钩', '铅头钩'
    hook_size_range TEXT,              -- 钩号范围: '2/0-4/0'

    weight_type TEXT,                  -- 配重类型: '子弹铅', '咬铅'
    weight_range_g TEXT,               -- 配重范围: '3.5-14g'

    additional_components TEXT,        -- 附加配件（JSON）: '["响珠", "八字环"]'

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 组装步骤
    -- ═══════════════════════════════════════════════════════════
    assembly_steps TEXT,               -- 组装步骤（JSON数组）
    assembly_difficulty TEXT CHECK(assembly_difficulty IN ('简单', '中等', '复杂')),
    assembly_time_minutes INTEGER,     -- 预计组装时间（分钟）
    key_points TEXT,                   -- 组装关键点

    -- ═══════════════════════════════════════════════════════════
    -- 🎣 操作技巧
    -- ═══════════════════════════════════════════════════════════
    operation_method TEXT,             -- 操作方式描述
    retrieve_speed TEXT CHECK(retrieve_speed IN ('极慢', '慢', '中速', '快', '变速')),
    rod_action TEXT,                   -- 竿动作: '抖动', '抽停', '拖动'
    best_technique TEXT,               -- 最佳操作手法

    -- ═══════════════════════════════════════════════════════════
    -- 📊 性能特点
    -- ═══════════════════════════════════════════════════════════
    casting_distance TEXT CHECK(casting_distance IN ('短', '中', '远', '极远')),
    snag_resistance TEXT CHECK(snag_resistance IN ('低', '中等', '高', '极高')),
    sensitivity TEXT CHECK(sensitivity IN ('低', '中等', '高', '极高')),
    versatility TEXT CHECK(versatility IN ('专用', '较通用', '通用')),

    -- ═══════════════════════════════════════════════════════════
    -- 📝 使用建议
    -- ═══════════════════════════════════════════════════════════
    recommended_rod_specs TEXT,        -- 推荐鱼竿规格（JSON）
    recommended_soft_baits TEXT,       -- 推荐软饵类型（JSON）
    usage_tips TEXT,                   -- 使用小贴士
    common_mistakes TEXT,              -- 常见错误

    -- 外键约束
    FOREIGN KEY (rig_type_id) REFERENCES rig_types(id) ON DELETE CASCADE
);
```

### 3.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **main_line_type** | TEXT | 主线类型 | `PE线`, `尼龙线` |
| **leader_length_cm** | TEXT | 前导线长度 | `30-50cm` |
| **assembly_steps** | TEXT | 组装步骤（JSON） | `["穿子弹铅", "绑曲柄钩", "穿软饵"]` |
| **operation_method** | TEXT | 操作方式 | `慢速拖动，逐步搜寻鱼讯` |
| **snag_resistance** | TEXT | 防挂能力 | `高`, `极高` |
| **usage_tips** | TEXT | 使用小贴士 | `适合在障碍区使用，操作时采用慢速拖动方式` |

## 4. 钓组配件组成表 (rig_components)

### 4.1 表结构

记录钓组与配件的组成关系。

```sql
CREATE TABLE rig_components (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    rig_type_id TEXT NOT NULL,         -- 关联rig_types.id
    accessory_type_id TEXT NOT NULL,   -- 关联accessory_types.id

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 组成关系
    -- ═══════════════════════════════════════════════════════════
    component_role TEXT NOT NULL,      -- 配件角色: '主线', '配重', '钩', '连接件', '辅助'
    is_required BOOLEAN DEFAULT TRUE,  -- 是否必需
    quantity INTEGER DEFAULT 1,        -- 数量
    position_order INTEGER,            -- 组装顺序

    -- ═══════════════════════════════════════════════════════════
    -- 📝 规格建议
    -- ═══════════════════════════════════════════════════════════
    recommended_spec TEXT,             -- 推荐规格: '3.5-7g', '#2-#4'
    alternative_types TEXT,            -- 可替代配件类型（JSON）
    notes TEXT,                        -- 备注说明

    -- ═══════════════════════════════════════════════════════════
    -- 🕐 元数据
    -- ═══════════════════════════════════════════════════════════
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 外键约束
    FOREIGN KEY (rig_type_id) REFERENCES rig_types(id) ON DELETE CASCADE,
    FOREIGN KEY (accessory_type_id) REFERENCES accessory_types(id) ON DELETE CASCADE,

    -- 唯一约束
    UNIQUE (rig_type_id, accessory_type_id, component_role)
);
```

### 4.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **rig_type_id** | TEXT | 钓组类型ID | `texas`, `carolina` |
| **accessory_type_id** | TEXT | 配件类型ID | `offset_hook`, `bullet_sinker` |
| **component_role** | TEXT | 配件角色 | `主线`, `配重`, `钩`, `连接件` |
| **is_required** | BOOLEAN | 是否必需 | `TRUE`/`FALSE` |
| **position_order** | INTEGER | 组装顺序 | `1`, `2`, `3` |
| **recommended_spec** | TEXT | 推荐规格 | `3.5-7g`, `3/0-4/0` |

```sql
CREATE TABLE rig_scenario_match (
    id INTEGER PRIMARY KEY AUTOINCREMENT,

    -- ═══════════════════════════════════════════════════════════

    target_fish TEXT,                  -- 目标鱼种: '黑鲈', '翘嘴', '鲶鱼'
```

## 7. 查询示例

### 7.1 查询特定类型的钓组

```python
def search_rigs(
    self,
    category: Optional[str] = None,
    difficulty_level: Optional[str] = None,
    water_type: Optional[str] = None,
    limit: int = 20
):
    """查询钓组"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT rt.*, rs.*
        FROM rig_types rt
        LEFT JOIN rig_specs rs ON rt.id = rs.rig_type_id
        WHERE rt.is_active = TRUE
    '''
    params = []

    if category:
        query += ' AND rt.category = ?'
        params.append(category)

    if difficulty_level:
        query += ' AND rt.difficulty_level = ?'
        params.append(difficulty_level)

    if water_type:
        query += ' AND rt.water_type IN (?, "通用")'
        params.append(water_type)

    query += ' ORDER BY rt.sort_order LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

**使用示例**：
```python
# 查询所有入门级钓组
beginner_rigs = db.search_rigs(difficulty_level='入门')

# 查询淡水软饵钓组
freshwater_rigs = db.search_rigs(category='经典软饵钓组', water_type='淡水')
```

### 7.2 查询钓组的配件组成

```python
def get_rig_components(self, rig_type_id: str):
    """获取钓组的配件组成"""
    conn = self._get_connection()
    cursor = conn.cursor()

    cursor.execute('''
        SELECT
            rc.component_role,
            rc.is_required,
            rc.quantity,
            rc.position_order,
            rc.recommended_spec,
            at.id as accessory_type_id,
            at.name_cn as accessory_name,
            at.name_en as accessory_name_en,
            at.category as accessory_category
        FROM rig_components rc
        JOIN accessory_types at ON rc.accessory_type_id = at.id
        WHERE rc.rig_type_id = ?
        ORDER BY rc.position_order
    ''', (rig_type_id,))

    return [dict(row) for row in cursor.fetchall()]
```

### 7.3 根据场景推荐钓组

```python
def recommend_rigs_for_scenario(
    self,
    scenario_type: str,
    target_fish: Optional[str] = None,
    season: Optional[str] = None,
    limit: int = 5
):
    """根据场景推荐钓组"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT
            rt.id, rt.name_cn, rt.name_en,
            rt.composition_summary, rt.advantages,
            rsm.effectiveness_score,
            rsm.usage_notes
        FROM rig_types rt
        JOIN rig_scenario_match rsm ON rt.id = rsm.rig_type_id
        WHERE rsm.scenario_type = ?
          AND rt.is_active = TRUE
    '''
    params = [scenario_type]

    if target_fish:
        query += ' AND rsm.target_fish = ?'
        params.append(target_fish)

    if season:
        query += ' AND rsm.season IN (?, "全季")'
        params.append(season)

    query += ' ORDER BY rsm.effectiveness_score DESC, rsm.priority_rank LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

### 7.4 查询适合特定钓组的鱼竿

```python
def find_rods_for_rig(
    self,
    rig_type_id: str,
    fitness_level: Optional[str] = None,
    limit: int = 20
):
    """根据钓组查询适配的鱼竿"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT
            e.id, e.name, e.brand,
            r.power, r.action, r.length,
            rlf.fitness_level,
            rlf.notes
        FROM equipment e
        JOIN rod_specs r ON e.id = r.equipment_id
        JOIN rod_lure_fitness rlf ON e.id = rlf.rod_equipment_id
        WHERE rlf.rig_type_id = ?
    '''
    params = [rig_type_id]

    if fitness_level:
        query += ' AND rlf.fitness_level = ?'
        params.append(fitness_level)

    query += ' ORDER BY rlf.fitness_level ASC, e.name LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

### 7.5 获取完整钓组信息

```python
def get_rig_full_info(self, rig_type_id: str):
    """获取钓组的完整信息（类型+规格+配件+场景）"""
    conn = self._get_connection()
    cursor = conn.cursor()

    # 基本信息
    cursor.execute('''
        SELECT rt.*, rs.*
        FROM rig_types rt
        LEFT JOIN rig_specs rs ON rt.id = rs.rig_type_id
        WHERE rt.id = ?
    ''', (rig_type_id,))
    basic_info = dict(cursor.fetchone()) if cursor.fetchone() else {}

    # 配件组成
    components = self.get_rig_components(rig_type_id)

    # 适用场景
    cursor.execute('''
        SELECT scenario_type, target_fish, season, effectiveness_score, usage_notes
        FROM rig_scenario_match
        WHERE rig_type_id = ?
        ORDER BY effectiveness_score DESC
    ''', (rig_type_id,))
    scenarios = [dict(row) for row in cursor.fetchall()]

    return {
        'basic_info': basic_info,
        'components': components,
        'scenarios': scenarios
    }
```
