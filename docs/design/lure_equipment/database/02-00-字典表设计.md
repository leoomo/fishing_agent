## 1. 设计概述

### 1.1 设计目标

字典表是**基础表**，被其他业务表引用，提供：

- **可扩展性**：动态增删饵类型、钓组类型，无需改表结构
- **数据一致性**：外键约束保证引用完整性
- **查询效率**：支持索引优化的适配度查询

### 1.2 表概览

| 表名 | 说明 | 记录数量级 |
|------|------|------------|
| **lure_types** | 饵类型字典 | ~20-30条 |
| **rig_types** | 钓组类型字典 | ~25条（v1.1扩展至21种钓组） |
| **accessory_types** | 配件类型字典（v1.1新增）| ~30条 |
| **rod_lure_fitness** | 竿-饵/钓组适配度 | ~N×M条 |

> **📌 配件类型字典表**：详见 [02-06-配件表设计](./02-06-配件表设计.md#2-配件类型字典表-accessory_types)
> **📌 钓组类型扩展**：详见 [02-07-钓组表设计](./02-07-钓组表设计.md#2-钓组类型字典表-rig_types)

## 2. 饵类型字典表 (lure_types)

### 2.1 表结构

```sql
CREATE TABLE lure_types (
    id TEXT PRIMARY KEY,               -- 类型ID: 'minnow', 'vib', 't_tail'
    name_cn TEXT NOT NULL,             -- 中文名: '米诺', 'VIB', 'T尾'
    name_en TEXT,                      -- 英文名: 'Minnow', 'VIB', 'Paddle Tail'
    category TEXT NOT NULL CHECK(category IN ('硬饵', '软饵', '金属饵')),
    parent_id TEXT,                    -- 父类型ID（支持层级分类）
    description TEXT,                  -- 类型描述
    typical_weight_min_g REAL,         -- 典型重量下限（克）
    typical_weight_max_g REAL,         -- 典型重量上限（克）
    typical_depth TEXT,                -- 典型泳层: '水面', '浅层', '中层', '深层', '全泳层'
    icon_url TEXT,                     -- 图标URL（可选）
    sort_order INTEGER DEFAULT 0,      -- 排序序号
    is_active BOOLEAN DEFAULT TRUE,    -- 是否启用
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (parent_id) REFERENCES lure_types(id)
);
```

### 2.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **id** | TEXT | 唯一标识，英文小写+下划线 | `minnow`, `vib`, `t_tail` |
| **name_cn** | TEXT | 中文名称 | `米诺`, `VIB`, `T尾` |
| **name_en** | TEXT | 英文名称 | `Minnow`, `VIB`, `Paddle Tail` |
| **category** | TEXT | 所属大类 | `硬饵`, `软饵`, `金属饵` |
| **parent_id** | TEXT | 父类型（支持层级） | `NULL`（顶级）或父ID |
| **typical_weight_min_g** | REAL | 该类型典型最小重量 | `5.0` |
| **typical_weight_max_g** | REAL | 该类型典型最大重量 | `25.0` |
| **typical_depth** | TEXT | 典型作钓泳层 | `浅层`, `全泳层` |
| **sort_order** | INTEGER | 显示排序 | `1`, `2`, `3`... |
| **is_active** | BOOLEAN | 是否启用 | `TRUE` |

## 4. 竿-饵/钓组适配度表 (rod_lure_fitness)

### 4.1 表结构

这是核心关联表，记录鱼竿对各类饵/钓组的适配程度。

```sql
CREATE TABLE rod_lure_fitness (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    rod_equipment_id TEXT NOT NULL,    -- 关联鱼竿 equipment.id

    -- ═══════════════════════════════════════════════════════════
    -- 🎯 适配目标（二选一）
    -- ═══════════════════════════════════════════════════════════
    lure_type_id TEXT,                 -- 关联饵类型 lure_types.id
    rig_type_id TEXT,                  -- 关联钓组类型 rig_types.id

    -- ═══════════════════════════════════════════════════════════
    -- ⭐ 适配度评级
    -- ═══════════════════════════════════════════════════════════
    fitness_level TEXT NOT NULL CHECK(fitness_level IN ('推荐', '适合', '勉强')),

    -- ═══════════════════════════════════════════════════════════
    -- 📝 补充说明
    -- ═══════════════════════════════════════════════════════════
    notes TEXT,                        -- 适配说明/使用建议
    weight_range_note TEXT,            -- 重量范围说明: '7-21g最佳'

    -- ═══════════════════════════════════════════════════════════
    -- 🕐 元数据
    -- ═══════════════════════════════════════════════════════════
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 外键约束
    FOREIGN KEY (rod_equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    FOREIGN KEY (lure_type_id) REFERENCES lure_types(id) ON DELETE CASCADE,
    FOREIGN KEY (rig_type_id) REFERENCES rig_types(id) ON DELETE CASCADE,

    -- 唯一约束：每竿每类型只能有一条记录
    UNIQUE (rod_equipment_id, lure_type_id),
    UNIQUE (rod_equipment_id, rig_type_id),

    -- 检查约束：必须指定饵类型或钓组类型之一
    CHECK (
        (lure_type_id IS NOT NULL AND rig_type_id IS NULL) OR
        (lure_type_id IS NULL AND rig_type_id IS NOT NULL)
    )
);
```

### 4.2 适配度等级说明

| 等级 | 含义 | 图标 | 典型场景 |
|------|------|------|----------|
| **推荐** | 专为此类设计，完美匹配 | ⭐⭐⭐ | 雷强竿→雷蛙，抽停竿→抽停饵 |
| **适合** | 可以使用，表现良好 | ⭐⭐ | MH通用竿→VIB，M竿→米诺 |
| **勉强** | 不太推荐，但能用 | ⭐ | 软饵竿→重型硬饵 |

### 4.3 使用场景

**场景1：专用竿的适配度**
```
雷强竿 (H-XH, F调)
├── 雷蛙: 推荐 ⭐⭐⭐
├── 虾型: 适合 ⭐⭐
├── 德州钓组: 推荐 ⭐⭐⭐
└── 米诺: 勉强 ⭐
```

**场景2：通用竿的适配度**
```
MH通用竿 (MH, F调)
├── 米诺: 适合 ⭐⭐
├── VIB: 推荐 ⭐⭐⭐
├── T尾: 适合 ⭐⭐
├── 德州钓组: 适合 ⭐⭐
└── 倒吊钓组: 适合 ⭐⭐
```

## 6. 查询示例

### 6.1 查询"推荐用米诺的鱼竿"

```python
def find_rods_for_lure_type(
    self,
    lure_type_id: str,
    fitness_level: Optional[str] = None,
    limit: int = 20
):
    """根据饵类型查询适配的鱼竿"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT
            e.id, e.name, e.brand,
            r.power, r.action, r.length,
            r.lure_weight_min_g, r.lure_weight_max_g,
            rlf.fitness_level,
            rlf.notes,
            lt.name_cn as lure_type_name
        FROM equipment e
        JOIN rod_specs r ON e.id = r.equipment_id
        JOIN rod_lure_fitness rlf ON e.id = rlf.rod_equipment_id
        JOIN lure_types lt ON rlf.lure_type_id = lt.id
        WHERE rlf.lure_type_id = ?
    '''
    params = [lure_type_id]

    if fitness_level:
        query += ' AND rlf.fitness_level = ?'
        params.append(fitness_level)

    query += ' ORDER BY rlf.fitness_level ASC, e.name LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

**使用示例**：

### 6.3 查询"某鱼竿的所有适配度"

```python
def get_rod_fitness_profile(self, rod_equipment_id: str):
    """获取鱼竿的完整适配度档案"""
    conn = self._get_connection()
    cursor = conn.cursor()

    # 查询饵类型适配度
    cursor.execute('''
        SELECT
            lt.id, lt.name_cn, lt.name_en, lt.category,
            rlf.fitness_level, rlf.notes
        FROM rod_lure_fitness rlf
        JOIN lure_types lt ON rlf.lure_type_id = lt.id
        WHERE rlf.rod_equipment_id = ?
        ORDER BY lt.category, lt.sort_order
    ''', (rod_equipment_id,))
    lure_fitness = [dict(row) for row in cursor.fetchall()]

    # 查询钓组适配度
    cursor.execute('''
        SELECT
            rt.id, rt.name_cn, rt.name_en,
            rlf.fitness_level, rlf.notes
        FROM rod_lure_fitness rlf
        JOIN rig_types rt ON rlf.rig_type_id = rt.id
        WHERE rlf.rod_equipment_id = ?
        ORDER BY rt.sort_order
    ''', (rod_equipment_id,))
    rig_fitness = [dict(row) for row in cursor.fetchall()]

    return {
        'rod_id': rod_equipment_id,
        'lure_fitness': lure_fitness,
        'rig_fitness': rig_fitness
    }
```

### 6.4 获取所有饵类型（带层级）

```python
def get_lure_types_tree(self, category: Optional[str] = None):
    """获取饵类型树形结构"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT id, name_cn, name_en, category, parent_id, sort_order
        FROM lure_types
        WHERE is_active = TRUE
    '''
    params = []

    if category:
        query += ' AND category = ?'
        params.append(category)

    query += ' ORDER BY category, sort_order'

    cursor.execute(query, params)
    rows = [dict(row) for row in cursor.fetchall()]

    # 构建树形结构
    tree = []
    lookup = {row['id']: {**row, 'children': []} for row in rows}

    for row in rows:
        node = lookup[row['id']]
        if row['parent_id']:
            parent = lookup.get(row['parent_id'])
            if parent:
                parent['children'].append(node)
        else:
            tree.append(node)

    return tree
```
