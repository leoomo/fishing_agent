**关系说明**：

| 关系 | 类型 | 说明 |
|------|------|------|
| equipment → rod_specs | 1:1 | 每个鱼竿装备对应一条规格记录 |

| rod_lure_fitness → rig_types | N:1 | 多条适配记录引用同一钓组类型 |

## 🗄️ rod_specs（鱼竿规格表）

### 表结构

将鱼竿的**高频查询字段**独立出来，优化查询性能。

```sql
CREATE TABLE rod_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id

    -- 🆕 高频查询场景字段
    fishing_type TEXT NOT NULL CHECK(fishing_type IN ('路亚', '台钓', '海钓', '矶钓', '筏钓', '通用')),
    water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')),
    target_species TEXT,               -- 目标鱼种（JSON数组）：'["黑鱼", "鲈鱼", "翘嘴"]'

    -- 核心物理规格
    length REAL NOT NULL CHECK(length > 0 AND length < 10), -- 长度（米）
    power TEXT CHECK(power IN ('UL', 'L', 'ML', 'M', 'MH', 'H', 'XH', 'XXH')), -- 硬度
    action TEXT CHECK(action IN ('SS', 'S', 'MS', 'M', 'MF', 'F', 'FF', 'XF')), -- 调性
    weight REAL CHECK(weight > 0 AND weight < 1000), -- 自重（克）

    -- 🔧 饵重范围（保留原始+解析值）
    lure_weight_raw TEXT,              -- 原始字符串："7-21g"、"1/8-3/4oz"
    lure_weight_min_g REAL CHECK(lure_weight_min_g >= 0), -- 最小值（克）
    lure_weight_max_g REAL CHECK(lure_weight_max_g >= lure_weight_min_g), -- 最大值（克）

    -- 🔧 材质信息
    carbon_grade TEXT,                 -- 碳布等级：24T/30T/36T/40T/46T
    base_material TEXT,                -- 基础材质：碳素/玻璃纤维/复合
    carbon_content REAL CHECK(carbon_content BETWEEN 0 AND 100), -- 碳含量（%）
    material_description TEXT,         -- 完整描述："36T高模量碳素"

    -- 扩展规格
    collapsed_length REAL CHECK(collapsed_length > 0), -- 收纳长度（米）
    sections_count INTEGER CHECK(sections_count BETWEEN 1 AND 10), -- 节数
    construction_type TEXT CHECK(construction_type IN ('并继', '振出', '伸缩')), -- 结构类型
    max_drag REAL CHECK(max_drag > 0), -- 最大承受力（kg）

    -- 🆕 握柄详细规格（v4.4新增）
    handle_style TEXT CHECK(handle_style IN (
        '直柄', '枪柄', '分体式', '一体式', '可拆卸'
    )),                                    -- 握柄样式
    handle_material TEXT,                  -- 握柄主材质：EVA/软木/碳纤维/复合材质
    handle_material_grade TEXT,            -- 材质等级：普通EVA/高密度EVA/葡萄牙软木/AAA软木
    handle_grip_shape TEXT CHECK(handle_grip_shape IN (
        '圆柱', '纺锤', '人体工学', '细腰', '锥形'
    )),                                    -- 握柄形状
    handle_rear_grip_length REAL CHECK(handle_rear_grip_length > 0), -- 后握长度（mm）
    handle_fore_grip_length REAL CHECK(handle_fore_grip_length > 0), -- 前握长度（mm）
    handle_total_length REAL CHECK(handle_total_length > 0), -- 握柄总长度（mm）
    handle_diameter REAL CHECK(handle_diameter > 0), -- 握柄直径（mm）
    reel_seat_type TEXT CHECK(reel_seat_type IN (
        '旋入式', '卡扣式', '可调节', '固定式'
    )),                                    -- 轮座类型
    reel_seat_material TEXT,               -- 轮座材质：铝合金/碳纤维/不锈钢/石墨

    -- 🆕 产品说明（v4.4新增）
    product_description TEXT,              -- 产品简介/卖点
    design_features TEXT,                  -- 设计特点（JSON数组）：'["高感度竿稀", "轻量化设计"]'
    usage_tips TEXT,                       -- 使用技巧/建议
    warranty_info TEXT,                    -- 保修信息

    -- 🆕 专用竿标识（v4.1新增，v4.2优化）
    -- 注意：详细的饵类型适配度请查阅 rod_lure_fitness 表
    is_specialized_rod BOOLEAN DEFAULT FALSE, -- 是否专用竿（快速标记）
    specialization_type TEXT,          -- 专用竿类型：雷强竿/抽停竿/软饵竿 等（可扩展）
    specialization_notes TEXT,         -- 专用竿说明

    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE
);
```

### 索引设计

```sql
-- 单字段索引（高频查询）
CREATE INDEX idx_rod_fishing_type ON rod_specs(fishing_type);
CREATE INDEX idx_rod_power ON rod_specs(power);
CREATE INDEX idx_rod_length ON rod_specs(length);
CREATE INDEX idx_rod_action ON rod_specs(action);
CREATE INDEX idx_rod_water_type ON rod_specs(water_type);

-- 🆕 复合索引（优化组合查询）
CREATE INDEX idx_rod_type_power ON rod_specs(fishing_type, power);
CREATE INDEX idx_rod_power_length ON rod_specs(power, length);

-- 🆕 专用竿索引（v4.1新增）
CREATE INDEX idx_rod_specialized ON rod_specs(is_specialized_rod, specialization_type);
```

**为什么单独建表**？
- 鱼竿的"钓法类型"、"硬度"、"长度"是最高频查询条件
- 独立表 + 索引 → 查询速度提升**10x**
- 其他装备类别查询频率低，保持JSON即可

### 📏 核心物理规格

| 字段 | 类型 | 约束 | 说明 | 示例 |
|------|------|------|------|------|
| **length** | REAL | NOT NULL, > 0, < 10 | 长度（米） | 2.64 |
| **power** | TEXT | 枚举 | 硬度等级 | `UL`/`L`/`ML`/`M`/`MH`/`H`/`XH`/`XXH` |
| **action** | TEXT | 枚举 | 调性 | `SS`/`S`/`MS`/`M`/`MF`/`F`/`FF`/`XF` |
| **weight** | REAL | > 0, < 1000 | 自重（克） | 105 |

**硬度等级说明**：
- **UL** (Ultra Light): 极软，适合小型鱼种
- **L** (Light): 软调，适合小饵
- **ML** (Medium Light): 中软
- **M** (Medium): 中调，通用性好
- **MH** (Medium Heavy): 中硬，路亚主流
- **H** (Heavy): 硬调，大鱼专用
- **XH** (Extra Heavy): 超硬
- **XXH**: 极硬

**调性说明**：
- **SS** (Super Slow): 超软调
- **S** (Slow): 软调（三七调）
- **MS** (Medium Slow): 中软调
- **M** (Medium): 中调（五五调）
- **MF** (Medium Fast): 中快调（四六调）
- **F** (Fast): 快调（二八调）
- **FF** (Fast Fast): 超快调
- **XF** (Extra Fast): 极快调（先调）

### ⚖️ 饵重范围（优化设计）

| 字段 | 类型 | 约束 | 说明 | 示例 |
|------|------|------|------|------|
| **lure_weight_raw** | TEXT | - | 原始字符串（保留单位） | `"7-21g"` / `"1/8-3/4oz"` |
| **lure_weight_min_g** | REAL | >= 0 | 最小值（统一为克） | 7.0 |
| **lure_weight_max_g** | REAL | >= min_g | 最大值（统一为克） | 21.0 |

**设计思路**：
- 保留原始值（`lure_weight_raw`）：保持数据溯源性，保留单位信息
- 存储解析值（`_min_g`/`_max_g`）：统一单位便于范围查询

## 🗄️ rod_guide_configurations（鱼竿导环配置表）

### 表结构

鱼竿与导环的配置关系表，支持灵活组合。

```sql
CREATE TABLE rod_guide_configurations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    rod_equipment_id TEXT NOT NULL,         -- 关联鱼竿equipment.id
    guide_equipment_id TEXT NOT NULL,       -- 关联导环equipment.id
    position_index INTEGER NOT NULL CHECK(position_index > 0), -- 位置索引（从竿稍到竿柄）
    position_name TEXT NOT NULL,            -- 位置名称 (TIP/TIP_TOP/RUNNING_1/STRIPPER)
    quantity INTEGER DEFAULT 1 CHECK(quantity > 0), -- 该位置导环数量
    distance_from_tip INTEGER CHECK(distance_from_tip >= 0), -- 距离竿稍距离 (mm)
    installation_method TEXT DEFAULT 'WRAPPING' CHECK(installation_method IN ('WRAPPING', 'GLUE', 'CLIP')),
    wrapping_color TEXT,                    -- 缠绕线颜色
    reinforcement BOOLEAN DEFAULT FALSE,    -- 是否加强处理
    is_mandatory BOOLEAN DEFAULT FALSE,     -- 是否必须配置
    is_alternative BOOLEAN DEFAULT FALSE,   -- 是否可选替代
    alternative_guide_ids TEXT,             -- 可替代导环ID (JSON)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (rod_equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    FOREIGN KEY (guide_equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    UNIQUE (rod_equipment_id, position_index)  -- 确保同一鱼竿同一位置只有一个配置
);
```

### 索引设计

```sql
CREATE INDEX idx_rod_guide_rod ON rod_guide_configurations(rod_equipment_id);
CREATE INDEX idx_rod_guide_guide ON rod_guide_configurations(guide_equipment_id);
CREATE INDEX idx_rod_guide_position ON rod_guide_configurations(position_index);
```

## 📈 查询示例

### 1. 基础查询：按钓法类型和硬度

```python
def search_rods(
    self,
    fishing_type: Optional[str] = None,
    power: Optional[str] = None,
    length_min: Optional[float] = None,
    length_max: Optional[float] = None,
    water_type: Optional[str] = None,
    price_max: Optional[float] = None,
    limit: int = 20
):
    """查询鱼竿（v4.0优化版）"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, r.*, b.reputation_score
        FROM equipment e
        JOIN rod_specs r ON e.id = r.equipment_id
        LEFT JOIN brands b ON e.brand = b.brand_name
        WHERE e.category = '鱼竿'
    '''
    params = []

    if fishing_type:
        query += ' AND r.fishing_type = ?'
        params.append(fishing_type)

    if power:
        query += ' AND r.power = ?'
        params.append(power)

    if length_min:
        query += ' AND r.length >= ?'
        params.append(length_min)

    if length_max:
        query += ' AND r.length <= ?'
        params.append(length_max)

    if water_type:
        query += ' AND r.water_type IN (?, "通用")'
        params.append(water_type)

    if price_max:
        query += ' AND e.price_min <= ?'
        params.append(price_max)

    query += ' ORDER BY b.reputation_score DESC, e.confidence DESC LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

**使用示例**：
```python

results = db.search_rods(
    fishing_type='路亚',
    water_type='淡水',
    power='MH',
    length_min=2.4,
    length_max=2.7,
    price_max=800
)
```

### 2. 高级查询：按饵重范围

```python
def search_rods_by_lure_weight(
    self,
    lure_weight_min: float,
    lure_weight_max: float,
    fishing_type: Optional[str] = None
):
    """按饵重范围查询鱼竿"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, r.*
        FROM equipment e
        JOIN rod_specs r ON e.id = r.equipment_id
        WHERE e.category = '鱼竿'
          AND r.lure_weight_min_g <= ?
          AND r.lure_weight_max_g >= ?
    '''
    params = [lure_weight_max, lure_weight_min]

    if fishing_type:
        query += ' AND r.fishing_type = ?'
        params.append(fishing_type)

    query += ' ORDER BY r.lure_weight_min_g ASC LIMIT 20'

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

**使用示例**：
```python

results = db.search_rods_by_lure_weight(
    lure_weight_min=10.0,
    lure_weight_max=15.0,
    fishing_type='路亚'
)
```

```python
def get_rod_guide_configuration(self, rod_equipment_id: str):
    """获取鱼竿的导环配置"""
    conn = self._get_connection()
    cursor = conn.cursor()

    cursor.execute('''
        SELECT
            rgc.position_index,
            rgc.position_name,
            rgc.quantity,
            rgc.distance_from_tip,
            e.name as guide_name,
            e.brand as guide_brand,
            gs.guide_type,
            gs.guide_size,
            gs.ring_material,
            gs.frame_type
        FROM rod_guide_configurations rgc
        JOIN equipment e ON rgc.guide_equipment_id = e.id
        LEFT JOIN guide_specs gs ON rgc.guide_equipment_id = gs.equipment_id
        WHERE rgc.rod_equipment_id = ?
        ORDER BY rgc.position_index
    ''', (rod_equipment_id,))

    return [dict(row) for row in cursor.fetchall()]
```
