## 1. 设计概述

### 1.1 设计目标

配件表用于管理路亚钓组所需的各类配件，支持：

- **完整配件体系**：钩类、配重、线类、连接件、辅助配件
- **钓组关联**：配件与钓组的组成关系
- **产品管理**：配件规格参数、品牌、价格
- **场景推荐**：根据钓组/场景推荐配件

### 1.2 配件分类体系

根据 `fishing_tools_knowledge.md` 知识库，配件分为以下5大类：

```

│   ├── 三本钩
│   ├── 飞蝇钩
│   └── 倒吊钩

│   ├── 子弹铅
│   ├── 咬铅
│   ├── 快挂铅
│   ├── 橄榄铅

│   ├── 自由铅

### 1.3 表结构概览

配件相关表共4个核心表 + 1个字典表：

| 表名 | 说明 | 记录数量级 |
|------|------|------------|
| **accessory_types** | 配件类型字典 | ~30条 |
| **accessory_specs** | 配件规格主表 | ~200+ |
| **hook_specs** | 钩类配件详情 | ~80+ |
| **weight_specs** | 配重配件详情 | ~50+ |
| **connector_specs** | 连接配件详情 | ~30+ |

### 1.4 关系图

```

## 2. 配件类型字典表 (accessory_types)

### 2.1 表结构

```sql
CREATE TABLE accessory_types (
    id TEXT PRIMARY KEY,               -- 类型ID: 'offset_hook', 'bullet_sinker'
    name_cn TEXT NOT NULL,             -- 中文名: '曲柄钩', '子弹铅'
    name_en TEXT,                      -- 英文名: 'Offset Hook', 'Bullet Sinker'
    category TEXT NOT NULL CHECK(category IN (
        '钩类', '配重', '线类', '连接件', '辅助配件'
    )),
    parent_id TEXT,                    -- 父类型ID（支持层级分类）
    description TEXT,                  -- 类型描述
    typical_use TEXT,                  -- 典型用途
    suitable_rigs TEXT,                -- 适用钓组（JSON数组）: '["texas", "carolina"]'
    icon_url TEXT,                     -- 图标URL（可选）
    sort_order INTEGER DEFAULT 0,      -- 排序序号
    is_active BOOLEAN DEFAULT TRUE,    -- 是否启用
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (parent_id) REFERENCES accessory_types(id)
);
```

### 2.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **id** | TEXT | 唯一标识，英文小写+下划线 | `offset_hook`, `bullet_sinker` |
| **name_cn** | TEXT | 中文名称 | `曲柄钩`, `子弹铅` |
| **name_en** | TEXT | 英文名称 | `Offset Hook`, `Bullet Sinker` |
| **category** | TEXT | 所属大类 | `钩类`, `配重`, `线类`, `连接件`, `辅助配件` |
| **suitable_rigs** | TEXT | 适用钓组（JSON） | `["texas", "carolina", "wacky"]` |
| **typical_use** | TEXT | 典型用途 | `德州钓组、维基钓组的核心钩型` |

## 3. 配件规格表 (accessory_specs)

### 3.1 表结构

配件的**通用规格**表，存储所有配件共有的属性。

```sql
CREATE TABLE accessory_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id

    -- ═══════════════════════════════════════════════════════════
    -- 🏷️ 分类体系
    -- ═══════════════════════════════════════════════════════════
    accessory_type_id TEXT NOT NULL,   -- 引用 accessory_types.id
    sub_type_id TEXT,                  -- 引用 accessory_types.id（子类型）

    -- ═══════════════════════════════════════════════════════════
    -- 📏 通用物理规格
    -- ═══════════════════════════════════════════════════════════
    material TEXT,                     -- 材质: '不锈钢', '铅合金', '碳纤维'
    material_grade TEXT,               -- 材质等级: '普通', '高强度', '环保可降解'
    weight_g REAL CHECK(weight_g > 0), -- 重量（克）
    spec_size TEXT,                    -- 规格号数: '#2', '3/0', '0.8#'
    spec_size_numeric REAL,            -- 数字化规格（便于排序）

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 适用范围
    -- ═══════════════════════════════════════════════════════════
    suitable_rigs TEXT,                -- 适用钓组（JSON数组）: '["texas", "carolina"]'
    suitable_line_types TEXT,          -- 适用线类型（JSON）: '["PE线", "碳线"]'
    water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')),

    -- ═══════════════════════════════════════════════════════════
    -- 📝 产品信息
    -- ═══════════════════════════════════════════════════════════
    pack_quantity INTEGER,             -- 包装数量
    color TEXT,                        -- 颜色
    is_eco_friendly BOOLEAN DEFAULT FALSE, -- 是否环保可降解（2025年新趋势）

    -- ═══════════════════════════════════════════════════════════
    -- ⭐ 性能评分（1-10分）
    -- ═══════════════════════════════════════════════════════════
    durability_score INTEGER CHECK(durability_score BETWEEN 1 AND 10),
    value_score INTEGER CHECK(value_score BETWEEN 1 AND 10),
    quality_score INTEGER CHECK(quality_score BETWEEN 1 AND 10),

    -- ═══════════════════════════════════════════════════════════
    -- 💰 商业信息
    -- ═══════════════════════════════════════════════════════════
    msrp_cny REAL CHECK(msrp_cny > 0),
    price_per_piece REAL,              -- 单件价格
    purchase_link TEXT,

    -- ═══════════════════════════════════════════════════════════
    -- 📦 扩展字段
    -- ═══════════════════════════════════════════════════════════
    features_2025 TEXT,                -- 2025年新趋势特性（JSON）: '["环保可降解", "智能识别"]'
    design_notes TEXT,                 -- 设计说明
    usage_tips TEXT,                   -- 使用技巧

    -- 外键约束
    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    FOREIGN KEY (accessory_type_id) REFERENCES accessory_types(id),
    FOREIGN KEY (sub_type_id) REFERENCES accessory_types(id)
);
```

### 3.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| **accessory_type_id** | TEXT | 配件类型引用 | `offset_hook`, `bullet_sinker` |
| **material** | TEXT | 主要材质 | `不锈钢`, `铅合金`, `环保可降解材质` |
| **material_grade** | TEXT | 材质等级 | `普通`, `高强度`, `环保` |
| **weight_g** | REAL | 重量（克） | `3.5`, `7.0` |
| **spec_size** | TEXT | 规格号数 | `#2`, `3/0`, `0.8#` |
| **suitable_rigs** | TEXT | 适用钓组（JSON） | `["texas", "carolina"]` |
| **is_eco_friendly** | BOOLEAN | 2025年环保标识 | `TRUE`/`FALSE` |
| **features_2025** | TEXT | 2025年新特性（JSON） | `["环保可降解", "钩尖角度可调"]` |

## 4. 钩类配件详情 (hook_specs)

### 4.1 表结构

钩类配件的**专用字段**表。

```sql
CREATE TABLE hook_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id + accessory_specs

    -- ═══════════════════════════════════════════════════════════
    -- 🪝 钩型参数
    -- ═══════════════════════════════════════════════════════════
    hook_type TEXT NOT NULL CHECK(hook_type IN (
        '曲柄钩', '铅头钩', '鸡爪钩', '三本钩', '飞蝇钩', '倒吊钩', '直柄钩', '圆钩'
    )),
    hook_style TEXT,                   -- 钩型样式: 'EWG', 'Wide Gap', 'Offset'
    shank_length TEXT CHECK(shank_length IN ('短柄', '标准', '长柄')),
    gap_width TEXT CHECK(gap_width IN ('窄钩门', '标准', '宽钩门')),
    point_type TEXT CHECK(point_type IN ('直钩尖', '内弯钩尖', '外弯钩尖')),
    barb_type TEXT CHECK(barb_type IN ('有倒刺', '无倒刺', '压倒刺')),

    -- ═══════════════════════════════════════════════════════════
    -- 📐 物理尺寸
    -- ═══════════════════════════════════════════════════════════
    hook_size TEXT NOT NULL,           -- 钩号: '#2', '#4', '1/0', '3/0'
    hook_size_numeric REAL,            -- 数字化钩号（便于排序）
    wire_diameter_mm REAL,             -- 钩线直径（mm）
    total_length_mm REAL,              -- 总长度（mm）

    -- ═══════════════════════════════════════════════════════════
    -- 🎣 钓组适配
    -- ═══════════════════════════════════════════════════════════
    suitable_soft_bait_types TEXT,     -- 适合的软饵类型（JSON）: '["t_tail", "craw"]'
    recommended_bait_size_inch TEXT,   -- 推荐软饵尺寸: '3-5inch'
    penetration_ability TEXT CHECK(penetration_ability IN ('低', '中等', '高', '极高')),

    -- ═══════════════════════════════════════════════════════════
    -- ⚙️ 2025年新特性
    -- ═══════════════════════════════════════════════════════════
    is_angle_adjustable BOOLEAN DEFAULT FALSE,  -- 钩尖角度可调节（2025新趋势）
    is_biodegradable BOOLEAN DEFAULT FALSE,     -- 环保可降解

    -- 外键约束
    FOREIGN KEY (equipment_id) REFERENCES accessory_specs(equipment_id) ON DELETE CASCADE
);
```

### 4.2 钩类型详解

根据知识库，6种主要钩类的特点：

| 钩类型 | 材质 | 规格范围 | 特点 | 适用钓组 |
|--------|------|----------|------|----------|
| **曲柄钩** | 不锈钢/环保材质 | 2-5号 (2-4克) | 穿障能力强，钩尖角度可调 | 德州、维基、咬铅 |
| **铅头钩** | 铅合金/环保材质 | 1-5号 (2-8克) | 重心可调，穿障能力好 | 铅头钩钓组、德州 |
| **鸡爪钩** | 不锈钢/环保材质 | 2-5号 (2-4克) | 钩尖角度大，适合硬饵 | 硬饵钓组 |
| **三本钩** | 不锈钢/环保材质 | 2-5号 (2-4克) | 三钩设计，适合硬饵 | 硬饵钓组 |
| **飞蝇钩** | 不锈钢/环保材质 | 1-3号 (1-3克) | 钩尖锋利，适合助投器 | 飞蝇钓组 |
| **倒吊钩** | 不锈钢/环保材质 | 2-4克 | 钩尖朝上，专用倒吊 | 倒吊钓组 |

## 5. 配重配件详情 (weight_specs)

### 5.1 表结构

配重配件的**专用字段**表。

```sql
CREATE TABLE weight_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id + accessory_specs

    -- ═══════════════════════════════════════════════════════════
    -- ⚖️ 配重参数
    -- ═══════════════════════════════════════════════════════════
    weight_type TEXT NOT NULL CHECK(weight_type IN (
        '子弹铅', '咬铅', '快挂铅', '橄榄铅', '倒钓铅', '自由铅', '助投器', '插铅'
    )),
    shape TEXT CHECK(shape IN (
        '子弹形', '圆形', '橄榄形', '长条形', '水滴形', '不规则'
    )),
    weight_g_min REAL CHECK(weight_g_min > 0),   -- 最小重量（克）
    weight_g_max REAL CHECK(weight_g_max >= weight_g_min), -- 最大重量（克）
    weight_oz TEXT,                    -- 盎司表示: '1/8oz', '1/4oz'

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 功能特性
    -- ═══════════════════════════════════════════════════════════
    is_sliding BOOLEAN DEFAULT FALSE,  -- 是否滑动型
    is_pegged BOOLEAN DEFAULT FALSE,   -- 是否可固定
    center_hole BOOLEAN DEFAULT FALSE, -- 是否有中心孔
    coating_type TEXT,                 -- 镀层类型: '无镀层', '镀黑', '荧光'

    -- ═══════════════════════════════════════════════════════════
    -- 🌊 下沉特性
    -- ═══════════════════════════════════════════════════════════
    sink_rate TEXT CHECK(sink_rate IN ('慢沉', '中速', '快沉')),
    noise_level TEXT CHECK(noise_level IN ('静音', '轻响', '响亮')),

    -- ═══════════════════════════════════════════════════════════
    -- ⚙️ 2025年新特性
    -- ═══════════════════════════════════════════════════════════
    is_biodegradable BOOLEAN DEFAULT FALSE,     -- 环保可降解
    is_weight_adjustable BOOLEAN DEFAULT FALSE, -- 重量可调节（智能化）

    -- 外键约束
    FOREIGN KEY (equipment_id) REFERENCES accessory_specs(equipment_id) ON DELETE CASCADE
);
```

### 5.2 配重类型详解

| **倒钓铅** | 铅合金/环保材质 | 2-4克 | 特殊形状，舍弃式 | 倒吊钓组 |
| **自由铅** | 铅合金/环保材质 | 1-6克 | 灵活使用，多用途 | 自由钓组 |

## 6. 连接配件详情 (connector_specs)

### 6.1 表结构

连接配件的**专用字段**表。

```sql
CREATE TABLE connector_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id + accessory_specs

    -- ═══════════════════════════════════════════════════════════
    -- 🔗 连接件参数
    -- ═══════════════════════════════════════════════════════════
    connector_type TEXT NOT NULL CHECK(connector_type IN (
        '别针', '八字环', '双圈', '三向转环', '响珠'
    )),
    connection_method TEXT,            -- 连接方式: '旋入式', '卡扣式', '穿线式'
    max_load_kg REAL,                  -- 最大承重（kg）

    -- ═══════════════════════════════════════════════════════════
    -- 📐 物理尺寸
    -- ═══════════════════════════════════════════════════════════
    ring_diameter_mm REAL,             -- 环直径（mm）
    wire_diameter_mm REAL,             -- 线材直径（mm）
    total_length_mm REAL,              -- 总长度（mm）

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 功能特性
    -- ═══════════════════════════════════════════════════════════
    is_rotating BOOLEAN DEFAULT FALSE, -- 是否旋转型
    rotation_smoothness TEXT CHECK(rotation_smoothness IN ('一般', '顺滑', '极顺滑')),
    has_sound BOOLEAN DEFAULT FALSE,   -- 是否发声（响珠）

    -- ═══════════════════════════════════════════════════════════
    -- ⚙️ 2025年新特性
    -- ═══════════════════════════════════════════════════════════
    is_eco_coating BOOLEAN DEFAULT FALSE,       -- 环保镀层
    is_size_adjustable BOOLEAN DEFAULT FALSE,   -- 大小可调节

    -- 外键约束
    FOREIGN KEY (equipment_id) REFERENCES accessory_specs(equipment_id) ON DELETE CASCADE
);
```

### 6.2 连接配件类型详解

根据知识库，5种主要连接配件的特点：

| 连接件类型 | 材质 | 特点 | 适用钓组 |
|------------|------|------|----------|
| **别针** | 不锈钢 | 整根钢丝制成，强度高 | 所有钓组 |
| **八字环** | 不锈钢/环保材质 | 连接主线和子线，可调节 | 卡罗莱纳、三向钓组 |
| **双圈** | 不锈钢/环保材质 | 连接钓线，可调节长度 | 多种钓组 |
| **三向转环** | 不锈钢/环保材质 | 连接多个子线，三向钓组专用 | 三向钓组 |
| **响珠** | 塑料/环保材质 | 增加声音效果，吸引鱼类 | 卡罗莱纳钓组 |

## 8. 查询示例

### 8.1 查询特定类型的配件

```python
def search_accessories(
    self,
    accessory_type_id: Optional[str] = None,
    category: Optional[str] = None,
    is_eco_friendly: Optional[bool] = None,
    limit: int = 20
):
    """查询配件"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, a.*, at.name_cn as type_name, at.category
        FROM equipment e
        JOIN accessory_specs a ON e.id = a.equipment_id
        JOIN accessory_types at ON a.accessory_type_id = at.id
        WHERE 1=1
    '''
    params = []

    if accessory_type_id:
        query += ' AND a.accessory_type_id = ?'
        params.append(accessory_type_id)

    if category:
        query += ' AND at.category = ?'
        params.append(category)

    if is_eco_friendly is not None:
        query += ' AND a.is_eco_friendly = ?'
        params.append(is_eco_friendly)

    query += ' ORDER BY a.quality_score DESC LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

**使用示例**：
```python
# 查询所有曲柄钩
offset_hooks = db.search_accessories(accessory_type_id='offset_hook')

# 查询所有环保配重
eco_weights = db.search_accessories(category='配重', is_eco_friendly=True)
```

def find_accessories_for_rig(
    self,
    rig_type_id: str,
    category: Optional[str] = None,
    limit: int = 20
):
    """根据钓组查询适配的配件"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, a.*, at.name_cn as type_name
        FROM equipment e
        JOIN accessory_specs a ON e.id = a.equipment_id
        JOIN accessory_types at ON a.accessory_type_id = at.id
        WHERE a.suitable_rigs LIKE ?
    '''
    params = [f'%{rig_type_id}%']

    if category:
        query += ' AND at.category = ?'
        params.append(category)

    query += ' ORDER BY a.quality_score DESC LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

def search_hooks(
    self,
    hook_type: Optional[str] = None,
    hook_size: Optional[str] = None,
    is_biodegradable: Optional[bool] = None,
    limit: int = 20
):
    """查询钩类配件"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, a.*, h.*
        FROM equipment e
        JOIN accessory_specs a ON e.id = a.equipment_id
        JOIN hook_specs h ON e.id = h.equipment_id
        WHERE 1=1
    '''
    params = []

    if hook_type:
        query += ' AND h.hook_type = ?'
        params.append(hook_type)

    if hook_size:
        query += ' AND h.hook_size = ?'
        params.append(hook_size)

    if is_biodegradable is not None:
        query += ' AND h.is_biodegradable = ?'
        params.append(is_biodegradable)

    query += ' ORDER BY h.hook_size_numeric LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

### 8.4 查询特定重量范围的配重

```python
def search_weights_by_range(
    self,
    weight_min: float,
    weight_max: float,
    weight_type: Optional[str] = None,
    limit: int = 20
):
    """按重量范围查询配重"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, a.*, w.*
        FROM equipment e
        JOIN accessory_specs a ON e.id = a.equipment_id
        JOIN weight_specs w ON e.id = w.equipment_id
        WHERE w.weight_g_min <= ? AND w.weight_g_max >= ?
    '''
    params = [weight_max, weight_min]

    if weight_type:
        query += ' AND w.weight_type = ?'
        params.append(weight_type)

    query += ' ORDER BY w.weight_g_min LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```
