## 📊 数据库选型

### SQLite + WAL模式

**选型理由**：
- ✅ 与项目fishing-agent保持一致（已用SQLite）
- ✅ 零配置部署（单文件数据库）
- ✅ 数据规模匹配（100-500款装备，<5MB）
- ✅ WAL模式支持并发读（99%读场景）
- ✅ 性能足够（支持50+ QPS）

**配置要求**：
```sql
PRAGMA journal_mode=WAL;           -- 核心：写前日志，支持并发读
PRAGMA synchronous=NORMAL;         -- 性能优化
PRAGMA cache_size=-64000;          -- 64MB缓存
PRAGMA busy_timeout=30000;         -- 锁等待30秒
PRAGMA temp_store=MEMORY;          -- 临时表放内存
```

### 1. equipment（装备主表）- 🔧 优化约束

存储所有装备的基础信息。

```sql
CREATE TABLE equipment (
    id TEXT PRIMARY KEY,              -- 装备唯一ID（如：shimano_poison_264mh）
    name TEXT NOT NULL,                -- 产品名称
    brand TEXT NOT NULL,               -- 品牌名称
    category TEXT NOT NULL CHECK(category IN ('鱼竿', '渔轮', '鱼线', '鱼饵', '鱼钩', '导环', '配件', '工具')), -- 🆕 添加枚举约束
    price_min REAL CHECK(price_min >= 0),   -- 🆕 价格必须非负
    price_max REAL CHECK(price_max >= price_min),  -- 🆕 最大价格≥最小价格
    specs_json TEXT,                   -- 🔧 规格参数（仅存储非结构化扩展字段，避免与专用表冗余）
    data_source TEXT CHECK(data_source IN ('manual', 'api', 'scraper')), -- 🆕 添加枚举约束
    last_verified DATE,                -- 最后验证日期
    confidence REAL DEFAULT 1.0 CHECK(confidence BETWEEN 0.0 AND 1.0), -- 🆕 添加范围约束
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (brand) REFERENCES brands(brand_name) ON UPDATE CASCADE -- 🆕 添加外键关联
);

-- 🆕 优化后的索引策略
CREATE INDEX idx_equipment_category ON equipment(category);
CREATE INDEX idx_equipment_brand ON equipment(brand);
CREATE INDEX idx_equipment_category_price ON equipment(category, price_min); -- 🆕 复合索引优化组合查询
CREATE INDEX idx_equipment_verified ON equipment(last_verified);
```

**字段说明**：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | TEXT | 唯一标识符 | `shimano_poison_264mh` |
| name | TEXT | 产品全称 | `禧玛诺毒牙21代 264MH` |
| brand | TEXT | 品牌名称 | `禧玛诺`/`Shimano` |
| category | TEXT | 装备分类 | `鱼竿`/`渔轮`/`鱼线` |
| price_min/max | REAL | 价格区间 | 650.0 / 750.0 |
| specs_json | TEXT | JSON规格 | `{"length": 2.64, "power": "MH"}` |
| data_source | TEXT | 数据来源标记 | `manual`/`api`/`scraper` |
| last_verified | DATE | 数据验证日期 | `2025-11-20` |
| confidence | REAL | 数据质量评分 | 0.0-1.0 (1.0最高) |

**specs_json使用说明**（🔧 避免数据冗余）：
- ✅ **存储内容**：非结构化字段、备注、自定义特性、扩展信息
- ❌ **不存储**：已在专用表中的字段（如rod_specs的length/power等）

```json
{
  "鱼竿": {
    "notes": "限量版涂装",
    "custom_features": ["防缠线设计", "快速收纳"],
    "warranty_years": 2,
    "color_options": ["黑色", "蓝色"]
  },
  "渔轮": {
    "notes": "2024新款",
    "color": "蓝色",
    "warranty_years": 3
  },
  "鱼线": {
    "notes": "高强度编织",
    "uv_resistant": true
  }
}
```

**说明**：鱼竿的核心规格（length、power、action等）已在`rod_specs`表中，无需在specs_json中重复存储。

### 2. rod_specs（鱼竿规格表）- 🔧 重大优化

将鱼竿的高频查询字段独立出来，优化查询性能。

```sql
CREATE TABLE rod_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id

    -- 🆕 新增：高频查询场景字段
    fishing_type TEXT NOT NULL CHECK(fishing_type IN ('路亚', '台钓', '海钓', '矶钓', '筏钓', '通用')), -- 钓法类型
    water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')), -- 水域类型
    target_species TEXT,               -- 目标鱼种（JSON数组）：'["黑鱼", "鲈鱼", "翘嘴"]'

    -- 核心物理规格
    length REAL NOT NULL CHECK(length > 0 AND length < 10), -- 长度（米）
    power TEXT CHECK(power IN ('UL', 'L', 'ML', 'M', 'MH', 'H', 'XH', 'XXH')), -- 硬度
    action TEXT CHECK(action IN ('SS', 'S', 'MS', 'M', 'MF', 'F', 'FF', 'XF')), -- 调性
    weight REAL CHECK(weight > 0 AND weight < 1000), -- 自重（克）

    -- 🔧 优化：饵重范围（保留原始+解析值）
    lure_weight_raw TEXT,              -- 原始字符串："7-21g"、"1/8-3/4oz"
    lure_weight_min_g REAL CHECK(lure_weight_min_g >= 0), -- 最小值（克）
    lure_weight_max_g REAL CHECK(lure_weight_max_g >= lure_weight_min_g), -- 最大值（克）

    -- 🔧 细化：材质信息
    carbon_grade TEXT,                 -- 碳布等级：24T/30T/36T/40T/46T
    base_material TEXT,                -- 基础材质：碳素/玻璃纤维/复合
    carbon_content REAL CHECK(carbon_content BETWEEN 0 AND 100), -- 碳含量（%）
    material_description TEXT,         -- 完整描述："36T高模量碳素"

    -- 扩展规格
    collapsed_length REAL CHECK(collapsed_length > 0), -- 收纳长度（米）
    sections_count INTEGER CHECK(sections_count BETWEEN 1 AND 10), -- 节数
    handle_type TEXT,                  -- 手柄类型：EVA/软木/橡胶/分体
    handle_length REAL CHECK(handle_length > 0), -- 手柄长度（米）
    construction_type TEXT CHECK(construction_type IN ('并继', '振出', '伸缩')), -- 结构类型
    max_drag REAL CHECK(max_drag > 0), -- 最大承受力（kg）

    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE
);

-- 🆕 优化后的索引策略
CREATE INDEX idx_rod_fishing_type ON rod_specs(fishing_type);
CREATE INDEX idx_rod_power ON rod_specs(power);
CREATE INDEX idx_rod_length ON rod_specs(length);
CREATE INDEX idx_rod_action ON rod_specs(action);
CREATE INDEX idx_rod_type_power ON rod_specs(fishing_type, power); -- 🆕 复合索引
CREATE INDEX idx_rod_power_length ON rod_specs(power, length);     -- 🆕 复合索引
CREATE INDEX idx_rod_water_type ON rod_specs(water_type);
```

**为什么单独建表**？
- 鱼竿的"硬度"、"长度"是最高频查询条件
- 独立表 + 索引 → 查询速度提升10x
- 其他装备类别查询频率低，保持JSON即可

## 🔧 数据库初始化代码

```python
# src/tools/lure/database.py

import sqlite3
from pathlib import Path
from typing import Optional
import threading

class ProductionSQLiteDB:
    """生产级SQLite数据库"""

    _instance = None
    _lock = threading.Lock()

    def __new__(cls, *args, **kwargs):
        """单例模式"""
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self, db_path: str = None):
        if hasattr(self, '_initialized'):
            return

        if db_path is None:
            db_path = Path(__file__).parent / "data" / "equipment.db"

        self.db_path = db_path
        self._local = threading.local()  # 线程本地连接
        self._init_database()
        self._initialized = True

    def _create_connection(self):
        """创建数据库连接"""
        conn = sqlite3.connect(
            self.db_path,
            timeout=30.0,
            check_same_thread=False
        )
        conn.row_factory = sqlite3.Row  # 返回字典格式

        # ⭐ 关键配置 ⭐
        conn.execute("PRAGMA journal_mode=WAL")
        conn.execute("PRAGMA synchronous=NORMAL")
        conn.execute("PRAGMA cache_size=-64000")
        conn.execute("PRAGMA busy_timeout=30000")
        conn.execute("PRAGMA temp_store=MEMORY")
        conn.execute("PRAGMA foreign_keys=ON")

        return conn

    def _get_connection(self):
        """获取线程本地连接"""
        if not hasattr(self._local, 'connection'):
            self._local.connection = self._create_connection()
        return self._local.connection

    def _init_database(self):
        """初始化数据库表结构"""
        conn = self._create_connection()
        cursor = conn.cursor()

        # 创建equipment表（优化版）
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS equipment (
                id TEXT PRIMARY KEY,
                name TEXT NOT NULL,
                brand TEXT NOT NULL,
                category TEXT NOT NULL CHECK(category IN ('鱼竿', '渔轮', '鱼线', '鱼饵', '鱼钩', '导环', '配件', '工具')),
                price_min REAL CHECK(price_min >= 0),
                price_max REAL CHECK(price_max >= price_min),
                specs_json TEXT,
                data_source TEXT CHECK(data_source IN ('manual', 'api', 'scraper')),
                last_verified DATE,
                confidence REAL DEFAULT 1.0 CHECK(confidence BETWEEN 0.0 AND 1.0),
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                FOREIGN KEY (brand) REFERENCES brands(brand_name) ON UPDATE CASCADE
            )
        ''')

        # 创建索引（优化版）
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_equipment_category ON equipment(category)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_equipment_brand ON equipment(brand)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_equipment_category_price ON equipment(category, price_min)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_equipment_verified ON equipment(last_verified)')

        # 创建rod_specs表（重大优化版）
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS rod_specs (
                equipment_id TEXT PRIMARY KEY,
                fishing_type TEXT NOT NULL CHECK(fishing_type IN ('路亚', '台钓', '海钓', '矶钓', '筏钓', '通用')),
                water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')),
                target_species TEXT,
                length REAL NOT NULL CHECK(length > 0 AND length < 10),
                power TEXT CHECK(power IN ('UL', 'L', 'ML', 'M', 'MH', 'H', 'XH', 'XXH')),
                action TEXT CHECK(action IN ('SS', 'S', 'MS', 'M', 'MF', 'F', 'FF', 'XF')),
                weight REAL CHECK(weight > 0 AND weight < 1000),
                lure_weight_raw TEXT,
                lure_weight_min_g REAL CHECK(lure_weight_min_g >= 0),
                lure_weight_max_g REAL CHECK(lure_weight_max_g >= lure_weight_min_g),
                carbon_grade TEXT,
                base_material TEXT,
                carbon_content REAL CHECK(carbon_content BETWEEN 0 AND 100),
                material_description TEXT,
                collapsed_length REAL CHECK(collapsed_length > 0),
                sections_count INTEGER CHECK(sections_count BETWEEN 1 AND 10),
                handle_type TEXT,
                handle_length REAL CHECK(handle_length > 0),
                construction_type TEXT CHECK(construction_type IN ('并继', '振出', '伸缩')),
                max_drag REAL CHECK(max_drag > 0),
                FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE
            )
        ''')

        # 创建索引（优化版）
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_fishing_type ON rod_specs(fishing_type)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_power ON rod_specs(power)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_length ON rod_specs(length)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_action ON rod_specs(action)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_type_power ON rod_specs(fishing_type, power)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_power_length ON rod_specs(power, length)')
        cursor.execute('CREATE INDEX IF NOT EXISTS idx_rod_water_type ON rod_specs(water_type)')

        # 创建brands表（修复版）
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS brands (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                brand_name TEXT UNIQUE NOT NULL,
                reputation_score REAL DEFAULT 50.0 CHECK(reputation_score BETWEEN 0.0 AND 100.0),
                country TEXT,
                tier TEXT CHECK(tier IN ('一线', '二线', '三线', '国产')),
                is_premium BOOLEAN DEFAULT 0,
                description TEXT,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
```

## 🔒 并发处理方案

### 问题：SQLite文件锁

**默认模式问题**：
```
写操作 → EXCLUSIVE锁 → 阻塞所有读写
读操作 → SHARED锁 → 被写操作阻塞
```

**WAL模式解决**：
```
写操作 → 写入.wal文件 → 不阻塞读操作 ✅
读操作 → 从主库+.wal文件读取 → 不被写阻塞 ✅
```

### 线程安全设计

```python
import threading

class ProductionSQLiteDB:
    def __init__(self):
        self._local = threading.local()  # 每个线程独立连接

    def _get_connection(self):
        """线程本地连接"""
        if not hasattr(self._local, 'connection'):
            self._local.connection = self._create_connection()
        return self._local.connection
```

**好处**：
- 每个线程有独立连接
- 避免连接共享导致的竞态条件
- 支持10+并发线程

### 事务与重试机制

```python
from contextlib import contextmanager
import time

@contextmanager
def transaction(self):
    """事务上下文管理器（自动重试）"""
    conn = self._get_connection()
    max_retries = 3

    for attempt in range(max_retries):
        try:
            conn.execute("BEGIN IMMEDIATE")  # 立即获取写锁
            yield conn
            conn.commit()
            return

        except sqlite3.OperationalError as e:
            conn.rollback()
            if "locked" in str(e) and attempt < max_retries - 1:
                time.sleep(0.1 * (2 ** attempt))  # 指数退避
                continue
            else:
                raise

# 使用示例
with db.transaction() as conn:
    cursor = conn.cursor()
    cursor.execute("INSERT INTO equipment VALUES (...)")
```

```python
    params = []

    if applicable_rod_type:
        query += ' AND JSON_EXTRACT(rgk.applicable_rod_types, ?) IS NOT NULL'
        params.append(f'$[?]' if applicable_rod_type else '$')

    if brand_id:
        query += ' AND rgk.brand_id = ?'
        params.append(brand_id)

    query += ' ORDER BY rgk.savings_percentage DESC'

    cursor.execute(query, params)
    results = {}
    for row in cursor.fetchall():
        kit_id = row['id']
        if kit_id not in results:
            results[kit_id] = {
                'kit_info': {k: v for k, v in dict(row).items()
                           if not k.startswith(('guide_', 'position_', 'quantity'))},
                'guides': []
            }
        results[kit_id]['guides'].append({
            'position_index': row['position_index'],
            'position_name': row['position_name'],
            'quantity': row['quantity'],
            'guide_name': row['guide_name'],
            'guide_size': row['guide_size'],
            'ring_material': row['ring_material']
        })

    return list(results.values())
```
