# 路亚装备查询工具设计文档

## 📋 项目概述

基于现有的fishing-agent项目，开发一个专业的路亚装备查询工具。采用**主工具+子方法**架构，通过智能自然语言处理支持复杂查询场景，降低LLM交互复杂度。

## 🎯 设计目标

### 1. 用户体验目标
- **零学习成本**: 用户只需自然语言查询，无需了解复杂参数
- **专业准确**: 提供7大类装备的详细技术参数和专业推荐
- **智能理解**: 自动识别装备类型、预算、场景、用户水平

### 2. 技术架构目标
- **单一入口**: LLM只需识别1个主工具，内部路由到7个子方法
- **复杂查询**: 支持单装备、装备组合、对比、场景化查询
- **可扩展性**: 易于添加新装备类型和推荐算法

## 🎣 装备分类体系

基于专业标准验证的7大类装备：

### 1. 鱼竿
- **硬度**: UUL-UL-L-ML-M-MH-H-XH-XXH (9级)
- **调性**: S-M-MF-F-XF (慢到快)
- **碳素吨位**: 24T-30T-36T-40T-46T
- **参数**: 长度、重量、饵重、适合线重

**详细硬度对照表**:
- **UUL**: 1-3g极轻饵，适合微物钓
- **UL**: 2-7g轻饵，适合溪流马口
- **L**: 4-10g轻饵，适合小型鲈鱼
- **ML**: 6-15g饵，万能调性，新手首选
- **M**: 8-20g饵，泛用性最强
- **MH**: 12-28g饵，适合大型鲈鱼
- **H**: 20-40g饵，适合海鲈等大鱼
- **XH**: 30-60g饵，重型路亚
- **XXH**: 50g+超重饵，海钓专用

### 2. 渔轮
- **类型**: 纺车轮、水滴轮、鼓轮
- **型号**: C2000-C4000型线容量对照
- **参数**: 齿轮比、轴承数、自重、材质

**纺车轮型号对照表**:
- **C2000型**: PE线0.6-1.0号，尼龙线2-4磅，微物专用
- **2500型**: PE线0.8-1.2号，尼龙线4-8磅，万能型号
- **3000型**: PE线1.0-1.5号，尼龙线6-12磅，泛用型
- **4000型**: PE线1.2-2.0号，尼龙线8-16磅，中大型

**齿轮比分类**:
- **低速比** (4.3-5.0:1): 力量型，适合搏击大鱼
- **中速比** (5.1-6.0:1): 万用速比，适合大多数钓法
- **高速比** (6.1-7.1:1): 快速收线，适合反应性钓法

### 3. 鱼线
- **类型**: PE线、尼龙线、碳线、氟碳线
- **参数**: 号数、直径、拉力值、延展性

**PE线号数对照表**:
| 号数 | 直径(mm) | 拉力值(kg) | 适用对象 |
|------|----------|------------|----------|
| 0.4号 | 0.104 | 0.88-1.33 | 微物 |
| 0.6号 | 0.128 | 1.51-1.80 | 小型鲈鱼 |
| 0.8号 | 0.148 | 1.80-2.30 | 中小型鲈鱼 |
| 1.0号 | 0.165 | 2.20-3.00 | 中型鲈鱼 |
| 1.2号 | 0.185 | 2.80-3.60 | 中大型鲈鱼 |
| 1.5号 | 0.205 | 3.50-4.50 | 大型鲈鱼 |
| 2.0号 | 0.235 | 4.50-6.00 | 海鲈、大物 |

**线种特性**:
- **PE线**: 无延展、感度高、拉力强、线径细
- **尼龙线**: 延展性好、结节强度高、价格便宜
- **碳线**: 比重大、切水性好、耐磨性强
- **氟碳线**: 透明度高、耐磨强、价格较高

### 4. 鱼饵
- **硬饵**: 米诺、波趴、铅笔、CRANK、VIB
- **软饵**: T尾、卷尾蛆、生物饵、雷蛙
- **参数**: 重量、尺寸、潜水深度、适用鱼种

**硬饵分类**:
- **米诺**: 3-15cm，2-30g，潜水0.3-4.0m，模仿小鱼
- **波趴**: 水面系，撞水效果，攻击性强
- **CRANK**: SR(0.5-1.5m)、MR(1.5-3.0m)、DR(3.0-5.0m)
- **VIB**: 3-20g，全水层搜索，高频振动
- **亮片**: 金属反光，诱鱼效果好

**软饵规格**:
- **T尾软虫**: 2.5-6寸，适合鲈鱼
- **卷尾蛆**: 1.8-4寸，适合微物
- **生物饵**: 3-7寸，仿真度高
- **雷蛙**: 防草设计，适合重草区

### 5. 鱼钩
- **类型**: 曲柄钩、直柄钩、圈形钩
- **参数**: 型号、材质、强度、适用场景

**钩型分类**:
- **曲柄钩**: 适合软饵，防挂草
- **直柄钩**: 适合硬饵，刺鱼快
- **圈形钩**: 适合海钓，强度高

### 6. 辅助配件
- **连接件**: 转环、别针、连接器
- **固定件**: 太空豆、挡豆、铅坠
- **线组**: 前导线、子线配置

**配件功能**:
- **转环**: 防止线组缠绕
- **别针**: 快速更换拟饵
- **太空豆**: 固定浮漂和铅坠
- **前导线**: 保护主线，防磨防断

### 7. 辅助工具
- **操作工具**: 路亚钳、控鱼器、摘钩器
- **辅助设备**: 抄网、路亚包、钓箱

### 推荐算法框架
```python
def _calculate_match_score(user_specs: Dict, equipment: Dict) -> float:
    """计算装备匹配度"""
    score = 0.0

    # 价格匹配 (30%)
    max_price = user_specs.get('price_max', 9999)
    if equipment['price'] <= max_price:
        price_ratio = equipment['price'] / max_price
        score += 30 * (1 - price_ratio * 0.5)  # 价格越低分数越高

    # 场景匹配 (25%)
    user_scenes = user_specs.get('scene', ['通用'])
    equipment_scenes = equipment.get('scene', ['通用'])
    scene_match = len(set(user_scenes) & set(equipment_scenes)) / len(set(user_scenes + equipment_scenes))
    score += 25 * scene_match

    # 用户水平匹配 (20%)
    user_levels = user_specs.get('user_level', ['通用'])
    equipment_levels = equipment.get('user_level', ['通用'])
    level_match = len(set(user_levels) & set(equipment_levels)) / len(set(user_levels + equipment_levels))
    score += 20 * level_match

    # 技术参数匹配 (25%)
    tech_score = _tech_specs_match(user_specs, equipment)
    score += 25 * tech_score

    return score

def _tech_specs_match(user_specs: Dict, equipment: Dict) -> float:
    """技术参数匹配计算"""
    match_score = 0.0
    total_checks = 0

    # 长度匹配
    if 'length' in user_specs and 'length' in equipment:
        total_checks += 1
        user_length = float(user_specs['length'])
        equip_length = equipment['length']
        if abs(user_length - equip_length) <= 0.3:  # 允许0.3米误差
            match_score += 1.0

    # 硬度匹配
    if 'power' in user_specs and 'power' in equipment:
        total_checks += 1
        if user_specs['power'] == equipment['power']:
            match_score += 1.0

    # 调性匹配
    if 'action' in user_specs and 'action' in equipment:
        total_checks += 1
        if user_specs['action'] == equipment['action']:
            match_score += 1.0

    return match_score / total_checks if total_checks > 0 else 0.5
```
