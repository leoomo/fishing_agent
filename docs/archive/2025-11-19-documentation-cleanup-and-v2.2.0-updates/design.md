# 文档清理和v2.2.0架构更新设计文档

本文档详细记录了智能钓鱼助手v2.2.0文档清理和架构更新的设计思路、技术决策和实施细节。

### 设计目标
- **简化**: 从47个文档精简到32个核心文档

### 内容策略设计

#### 🎯 内容层次原则

1. **渐进式披露**
   ```
   README.md (5分钟了解)
   → CLAUDE.md (30分钟上手)
   → 详细文档 (深入使用)
   ```

2. **零假设原则**
   - 不假设用户有任何先验知识
   - 提供完整的配置步骤
   - 包含所有必需的依赖和环境

3. **实践导向**
   - 每个概念都有可执行的示例
   - 提供真实的测试命令
   - 包含常见问题的解决方案
