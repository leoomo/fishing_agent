## 概述

本文档定义基于Chroma的向量知识库设计，用于实现：
1. **知识语义搜索** - 理解用户自然语言查询
2. **图片向量化** - 支持以图搜图功能
3. **跨模态搜索** - 文字描述搜索图片

## 技术选型

### 为什么选择Chroma？

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **Chroma** | 轻量嵌入式、零配置、Python原生 | 大规模性能有限 | 中小规模（<100万向量）|
| pgvector | 与PostgreSQL集成 | 需要迁移数据库 | 已有PostgreSQL项目 |
| Milvus | 高性能、分布式 | 部署复杂 | 大规模向量检索 |
| Pinecone | 托管服务、免运维 | 成本高、数据出境 | 商业项目 |

**选择Chroma的理由**：
- ✅ 与SQLite理念一致（嵌入式、零配置）
- ✅ 支持持久化存储
- ✅ Python原生，无需额外服务
- ✅ 支持多种Embedding模型
- ✅ 数据规模（<10万条知识）完全够用

### Embedding模型选型

| 模型 | 类型 | 用途 | 维度 | 说明 |
|------|------|------|------|------|
| **BGE-M3** | 文本 | 知识向量化 | 1024 | 中文支持最佳 |
| **AltCLIP** | 多模态 | 图片向量化 | 768 | 中文多模态 |
| text-embedding-3-small | 文本 | 备选方案 | 1536 | OpenAI API |

## 架构设计

### 向量库结构

```
Chroma Vector Store
├── fish_knowledge          # 鱼类知识集合
│   ├── embedding: BGE-M3
│   └── metadata: {knowledge_id, fish_id, type, tags}
│
├── rig_knowledge           # 钓组知识集合
│   ├── embedding: BGE-M3
│   └── metadata: {knowledge_id, rig_type, tags}
│
├── equipment_descriptions  # 装备描述集合
│   ├── embedding: BGE-M3
│   └── metadata: {equipment_id, category, brand}
│
└── image_embeddings        # 图片向量集合
    ├── embedding: AltCLIP
    └── metadata: {image_id, entity_type, entity_id}
```

### 与SQLite的关系

```
┌─────────────────────────────────────────────────────────────────┐
│                       查询流程                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户查询: "春天钓鲈鱼用什么饵？"                                 │
│       │                                                         │
│       ▼                                                         │
│  ┌─────────────────┐                                           │
│  │  BGE-M3 模型    │  将查询文本向量化                          │
│  └────────┬────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  ┌─────────────────┐                                           │
│  │  Chroma搜索     │  相似度搜索 → 返回knowledge_id列表         │
│  │  fish_knowledge │                                           │
│  └────────┬────────┘                                           │
│           │ [id: 23, id: 45, id: 12]                           │
│           ▼                                                     │
│  ┌─────────────────┐                                           │
│  │  SQLite查询     │  SELECT * FROM fish_knowledge             │
│  │                 │  WHERE id IN (23, 45, 12)                 │
│  └────────┬────────┘                                           │
│           │                                                     │
│           ▼                                                     │
│  返回完整知识内容 + 关联图片                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**设计原则**：
- Chroma只存储向量和关键元数据（ID、类型）
- 完整内容存储在SQLite中
- 搜索结果通过ID回查SQLite获取详情

## VectorStore 封装设计

### 核心接口

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional
from dataclasses import dataclass


@dataclass
class SearchResult:
    """搜索结果"""
    id: str
    score: float
    metadata: Dict[str, Any]


class VectorStoreAdapter(ABC):
    """向量存储适配器抽象基类"""

    @abstractmethod
    def add_texts(
        self,
        collection: str,
        texts: List[str],
        ids: List[str],
        metadatas: List[Dict[str, Any]]
    ) -> None:
        """添加文本向量"""
        pass

    @abstractmethod
    def add_images(
        self,
        collection: str,
        image_paths: List[str],
        ids: List[str],
        metadatas: List[Dict[str, Any]]
    ) -> None:
        """添加图片向量"""
        pass

    @abstractmethod
    def search_by_text(
        self,
        collection: str,
        query_text: str,
        top_k: int = 5,
        filters: Optional[Dict] = None
    ) -> List[SearchResult]:
        """文本查询"""
        pass

    @abstractmethod
    def search_by_image(
        self,
        collection: str,
        image_path: str,
        top_k: int = 5,
        filters: Optional[Dict] = None
    ) -> List[SearchResult]:
        """图片查询"""
        pass

    @abstractmethod
    def delete(self, collection: str, ids: List[str]) -> None:
        """删除向量"""
        pass
```

### Chroma实现

```python
import chromadb
from chromadb.config import Settings
from sentence_transformers import SentenceTransformer
from PIL import Image
import torch


class ChromaVectorStore(VectorStoreAdapter):
    """Chroma向量存储实现"""

    def __init__(self, persist_directory: str):
        # 初始化Chroma客户端（持久化存储）
        self.client = chromadb.PersistentClient(
            path=persist_directory,
            settings=Settings(anonymized_telemetry=False)
        )

        # 初始化Embedding模型
        self.text_model = None  # 懒加载
        self.image_model = None  # 懒加载

        # 集合缓存
        self._collections = {}

    def _get_text_model(self):
        """懒加载文本Embedding模型"""
        if self.text_model is None:
            self.text_model = SentenceTransformer('BAAI/bge-m3')
        return self.text_model

    def _get_image_model(self):
        """懒加载图片Embedding模型"""
        if self.image_model is None:
            # 使用AltCLIP或其他CLIP模型
            from transformers import AltCLIPModel, AltCLIPProcessor
            self.image_model = AltCLIPModel.from_pretrained("BAAI/AltCLIP")
            self.image_processor = AltCLIPProcessor.from_pretrained("BAAI/AltCLIP")
        return self.image_model

    def _get_collection(self, name: str):
        """获取或创建集合"""
        if name not in self._collections:
            self._collections[name] = self.client.get_or_create_collection(
                name=name,
                metadata={"hnsw:space": "cosine"}  # 使用余弦相似度
            )
        return self._collections[name]

    # ========== 文本操作 ==========

    def add_texts(
        self,
        collection: str,
        texts: List[str],
        ids: List[str],
        metadatas: List[Dict[str, Any]]
    ) -> None:
        """添加文本向量"""
        model = self._get_text_model()
        embeddings = model.encode(texts, normalize_embeddings=True)

        col = self._get_collection(collection)
        col.add(
            embeddings=embeddings.tolist(),
            documents=texts,
            ids=ids,
            metadatas=metadatas
        )

    def search_by_text(
        self,
        collection: str,
        query_text: str,
        top_k: int = 5,
        filters: Optional[Dict] = None
    ) -> List[SearchResult]:
        """文本语义搜索"""
        model = self._get_text_model()
        query_embedding = model.encode([query_text], normalize_embeddings=True)

        col = self._get_collection(collection)

        results = col.query(
            query_embeddings=query_embedding.tolist(),
            n_results=top_k,
            where=filters
        )

        return self._parse_results(results)

    # ========== 图片操作 ==========

    def add_images(
        self,
        collection: str,
        image_paths: List[str],
        ids: List[str],
        metadatas: List[Dict[str, Any]]
    ) -> None:
        """添加图片向量"""
        model = self._get_image_model()
        embeddings = []

        for path in image_paths:
            image = Image.open(path)
            inputs = self.image_processor(images=image, return_tensors="pt")

            with torch.no_grad():
                image_features = model.get_image_features(**inputs)
                embedding = image_features / image_features.norm(dim=-1, keepdim=True)
                embeddings.append(embedding.squeeze().numpy())

        col = self._get_collection(collection)
        col.add(
            embeddings=embeddings,
            ids=ids,
            metadatas=metadatas
        )

    def search_by_image(
        self,
        collection: str,
        image_path: str,
        top_k: int = 5,
        filters: Optional[Dict] = None
    ) -> List[SearchResult]:
        """以图搜图"""
        model = self._get_image_model()
        image = Image.open(image_path)
        inputs = self.image_processor(images=image, return_tensors="pt")

        with torch.no_grad():
            image_features = model.get_image_features(**inputs)
            query_embedding = image_features / image_features.norm(dim=-1, keepdim=True)

        col = self._get_collection(collection)

        results = col.query(
            query_embeddings=query_embedding.squeeze().numpy().tolist(),
            n_results=top_k,
            where=filters
        )

        return self._parse_results(results)

    def search_image_by_text(
        self,
        collection: str,
        query_text: str,
        top_k: int = 5,
        filters: Optional[Dict] = None
    ) -> List[SearchResult]:
        """用文字描述搜索图片（跨模态）"""
        model = self._get_image_model()
        inputs = self.image_processor(text=[query_text], return_tensors="pt", padding=True)

        with torch.no_grad():
            text_features = model.get_text_features(**inputs)
            query_embedding = text_features / text_features.norm(dim=-1, keepdim=True)

        col = self._get_collection(collection)

        results = col.query(
            query_embeddings=query_embedding.squeeze().numpy().tolist(),
            n_results=top_k,
            where=filters
        )

        return self._parse_results(results)

    # ========== 删除操作 ==========

    def delete(self, collection: str, ids: List[str]) -> None:
        """删除向量"""
        col = self._get_collection(collection)
        col.delete(ids=ids)

    # ========== 私有方法 ==========

    def _parse_results(self, results: Dict) -> List[SearchResult]:
        """解析Chroma返回结果"""
        search_results = []

        if results['ids'] and results['ids'][0]:
            for i, id in enumerate(results['ids'][0]):
                search_results.append(SearchResult(
                    id=id,
                    score=1 - results['distances'][0][i] if results['distances'] else 0,
                    metadata=results['metadatas'][0][i] if results['metadatas'] else {}
                ))

        return search_results
```

## 知识索引管理

### KnowledgeIndexer 类

```python
class KnowledgeIndexer:
    """知识索引管理器"""

    def __init__(self, db, vector_store: ChromaVectorStore):
        self.db = db
        self.vector_store = vector_store

    def index_fish_knowledge(self, batch_size: int = 100) -> int:
        """索引鱼类知识"""
        # 获取未索引的知识
        query = """
            SELECT id, fish_species_id, knowledge_type, title, content, tags
            FROM fish_knowledge
            WHERE is_vectorized = 0
            LIMIT ?
        """
        rows = self.db.execute(query, (batch_size,))

        if not rows:
            return 0

        # 准备数据
        texts = []
        ids = []
        metadatas = []

        for row in rows:
            # 组合文本：标题 + 内容摘要
            text = f"{row['title']}\n{row['content'][:500]}"
            texts.append(text)
            ids.append(f"fk_{row['id']}")
            metadatas.append({
                "knowledge_id": row['id'],
                "fish_id": row['fish_species_id'],
                "type": row['knowledge_type'],
                "tags": row['tags'] or ""
            })

        # 添加到向量库
        self.vector_store.add_texts(
            collection="fish_knowledge",
            texts=texts,
            ids=ids,
            metadatas=metadatas
        )

        # 更新索引状态
        knowledge_ids = [row['id'] for row in rows]
        self._mark_indexed("fish_knowledge", knowledge_ids)

        return len(rows)

    def index_rig_knowledge(self, batch_size: int = 100) -> int:
        """索引钓组知识"""
        query = """
            SELECT rs.id, rs.rig_type_id, rt.name_cn, rs.description,
                   rs.assembly_steps, rs.operation_tips
            FROM rig_specs rs
            JOIN rig_types rt ON rs.rig_type_id = rt.id
            WHERE rs.is_vectorized = 0
            LIMIT ?
        """
        rows = self.db.execute(query, (batch_size,))

        if not rows:
            return 0

        texts = []
        ids = []
        metadatas = []

        for row in rows:
            text = f"{row['name_cn']}\n{row['description']}\n{row['assembly_steps']}"
            texts.append(text)
            ids.append(f"rk_{row['id']}")
            metadatas.append({
                "rig_spec_id": row['id'],
                "rig_type_id": row['rig_type_id'],
                "name": row['name_cn']
            })

        self.vector_store.add_texts(
            collection="rig_knowledge",
            texts=texts,
            ids=ids,
            metadatas=metadatas
        )

        rig_ids = [row['id'] for row in rows]
        self._mark_indexed("rig_specs", rig_ids, "is_vectorized")

        return len(rows)

    def index_images(self, batch_size: int = 50) -> int:
        """索引图片"""
        query = """
            SELECT image_id, image_url, description,
                   equipment_id, rig_type_id, fish_species_id
            FROM product_images
            WHERE is_vectorized = 0
            LIMIT ?
        """
        rows = self.db.execute(query, (batch_size,))

        if not rows:
            return 0

        image_paths = []
        ids = []
        metadatas = []

        for row in rows:
            # 确定实体类型
            if row['equipment_id']:
                entity_type = "equipment"
                entity_id = row['equipment_id']
            elif row['rig_type_id']:
                entity_type = "rig"
                entity_id = row['rig_type_id']
            else:
                entity_type = "fish"
                entity_id = row['fish_species_id']

            image_paths.append(self._url_to_path(row['image_url']))
            ids.append(f"img_{row['image_id']}")
            metadatas.append({
                "image_id": row['image_id'],
                "entity_type": entity_type,
                "entity_id": entity_id,
                "description": row['description'] or ""
            })

        self.vector_store.add_images(
            collection="image_embeddings",
            image_paths=image_paths,
            ids=ids,
            metadatas=metadatas
        )

        image_ids = [row['image_id'] for row in rows]
        self._mark_images_indexed(image_ids)

        return len(rows)

    def reindex_all(self) -> Dict[str, int]:
        """重建所有索引"""
        # 清空现有索引
        self.vector_store.client.delete_collection("fish_knowledge")
        self.vector_store.client.delete_collection("rig_knowledge")
        self.vector_store.client.delete_collection("image_embeddings")

        # 重置索引状态
        self.db.execute_write("UPDATE fish_knowledge SET is_vectorized = 0")
        self.db.execute_write("UPDATE rig_specs SET is_vectorized = 0")
        self.db.execute_write("UPDATE product_images SET is_vectorized = 0")

        # 重新索引
        results = {
            "fish_knowledge": 0,
            "rig_knowledge": 0,
            "images": 0
        }

        while True:
            count = self.index_fish_knowledge()
            results["fish_knowledge"] += count
            if count == 0:
                break

        while True:
            count = self.index_rig_knowledge()
            results["rig_knowledge"] += count
            if count == 0:
                break

        while True:
            count = self.index_images()
            results["images"] += count
            if count == 0:
                break

        return results

    def _mark_indexed(self, table: str, ids: List[int], column: str = "is_vectorized"):
        placeholders = ",".join(["?"] * len(ids))
        query = f"UPDATE {table} SET {column} = 1 WHERE id IN ({placeholders})"
        self.db.execute_write(query, tuple(ids))

    def _mark_images_indexed(self, image_ids: List[int]):
        placeholders = ",".join(["?"] * len(image_ids))
        query = f"""
            UPDATE product_images
            SET is_vectorized = 1, embedding_id = 'img_' || image_id
            WHERE image_id IN ({placeholders})
        """
        self.db.execute_write(query, tuple(image_ids))

    def _url_to_path(self, url: str) -> str:
        if url.startswith("file://"):
            return url[7:]
        return url
```

## 搜索服务

### KnowledgeSearchService 类

```python
class KnowledgeSearchService:
    """知识搜索服务"""

    def __init__(self, db, vector_store: ChromaVectorStore, image_manager):
        self.db = db
        self.vector_store = vector_store
        self.image_manager = image_manager

    def search_knowledge(
        self,
        query: str,
        knowledge_types: Optional[List[str]] = None,
        fish_id: Optional[int] = None,
        top_k: int = 5
    ) -> List[Dict[str, Any]]:
        """搜索知识（语义搜索 + SQL详情）"""
        # 构建过滤器
        filters = {}
        if knowledge_types:
            filters["type"] = {"$in": knowledge_types}
        if fish_id:
            filters["fish_id"] = fish_id

        # 向量搜索
        results = self.vector_store.search_by_text(
            collection="fish_knowledge",
            query_text=query,
            top_k=top_k,
            filters=filters if filters else None
        )

        # 获取完整内容
        knowledge_ids = [int(r.metadata["knowledge_id"]) for r in results]
        return self._get_knowledge_details(knowledge_ids, results)

    def search_rig(self, query: str, top_k: int = 5) -> List[Dict[str, Any]]:
        """搜索钓组知识"""
        results = self.vector_store.search_by_text(
            collection="rig_knowledge",
            query_text=query,
            top_k=top_k
        )

        rig_ids = [int(r.metadata["rig_spec_id"]) for r in results]
        return self._get_rig_details(rig_ids, results)

    def identify_image(
        self,
        image_path: str,
        top_k: int = 3
    ) -> List[Dict[str, Any]]:
        """以图搜图识别"""
        results = self.vector_store.search_by_image(
            collection="image_embeddings",
            image_path=image_path,
            top_k=top_k
        )

        return self._get_image_entity_details(results)

    def search_image_by_description(
        self,
        description: str,
        entity_type: Optional[str] = None,
        top_k: int = 5
    ) -> List[Dict[str, Any]]:
        """用文字描述搜索图片"""
        filters = {"entity_type": entity_type} if entity_type else None

        results = self.vector_store.search_image_by_text(
            collection="image_embeddings",
            query_text=description,
            top_k=top_k,
            filters=filters
        )

        return self._get_image_entity_details(results)

    def _get_knowledge_details(
        self,
        knowledge_ids: List[int],
        search_results: List[SearchResult]
    ) -> List[Dict[str, Any]]:
        """获取知识详情"""
        if not knowledge_ids:
            return []

        placeholders = ",".join(["?"] * len(knowledge_ids))
        query = f"""
            SELECT fk.*, fs.name_cn as fish_name
            FROM fish_knowledge fk
            LEFT JOIN fish_species fs ON fk.fish_species_id = fs.id
            WHERE fk.id IN ({placeholders})
        """
        rows = self.db.execute(query, tuple(knowledge_ids))

        # 构建ID到行的映射
        row_map = {row['id']: row for row in rows}

        # 按搜索结果顺序返回
        results = []
        for sr in search_results:
            kid = int(sr.metadata["knowledge_id"])
            if kid in row_map:
                row = row_map[kid]
                results.append({
                    "id": kid,
                    "score": sr.score,
                    "title": row['title'],
                    "content": row['content'],
                    "knowledge_type": row['knowledge_type'],
                    "fish_name": row.get('fish_name'),
                    "tags": row.get('tags')
                })

        return results

    def _get_image_entity_details(
        self,
        search_results: List[SearchResult]
    ) -> List[Dict[str, Any]]:
        """获取图片关联实体详情"""
        results = []

        for sr in search_results:
            entity_type = sr.metadata["entity_type"]
            entity_id = sr.metadata["entity_id"]
            image_id = sr.metadata["image_id"]

            # 根据实体类型查询详情
            if entity_type == "equipment":
                entity = self._get_equipment(entity_id)
            elif entity_type == "rig":
                entity = self._get_rig(entity_id)
            else:
                entity = self._get_fish(entity_id)

            # 获取图片信息
            image = self._get_image(image_id)

            results.append({
                "score": sr.score,
                "entity_type": entity_type,
                "entity": entity,
                "image": image
            })

        return results
```

```python
    query="春天钓鲈鱼用什么饵最好",
    top_k=5
)

for r in results:
    print(f"[{r['score']:.2f}] {r['title']}")
    print(f"  类型: {r['knowledge_type']}")
    print(f"  鱼种: {r['fish_name']}")
```
