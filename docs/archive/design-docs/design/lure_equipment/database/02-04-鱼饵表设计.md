## 1. 设计概述

### 1.1 设计目标与范围

本设计涵盖路亚拟饵（Lure）的完整产品资料库，支持：

- **产品管理**：完整的拟饵规格参数记录
- **分类检索**：多维度分类体系支持精准查询
- **竿饵匹配**：双向关联体系，支持"专用竿"概念
- **场景推荐**：基于目标鱼种、水域、季节的智能推荐

### 1.2 分表设计理由

采用**分表设计**（硬饵/软饵/金属饵三张独立表），原因如下：

| 对比维度 | 统一表设计 | 分表设计 ✅ |
|----------|------------|-------------|
| 字段利用率 | 低（大量NULL） | 高（字段针对性强） |
| 查询效率 | 需过滤类型 | 直接查询目标表 |
| 扩展性 | 改表影响全局 | 独立扩展不影响 |
| 业务语义 | 模糊 | 清晰（硬饵有唇板，软饵有气味） |

### 1.3 竿饵关联设计理念

路亚钓鱼中，**竿饵匹配是核心**。很多专业鱼竿是为特定类型的饵设计的：

| 专用竿类型 | 目标饵型 | 竿特征要求 | 典型场景 |
|------------|----------|------------|----------|
| **雷强竿** | 雷蛙 | H-XH硬度、快调、强力腰身 | 重草区打黑 |
| **抽停竿** | Jerkbait/抽停饵 | M-MH、XF调性、敏感竿稀 | 冷水期悬停诱鱼 |
| **软饵竿** | 德州/倒吊/Neko | ML-M、F调性、高灵敏度 | 精细作钓 |
| **亮片竿** | 金属亮片/铁板 | M-MH、远投性能 | 岸钓远投 |
| **深潜竿** | Deep Crank | M调、慢回弹、玻纤混合 | 深水搜索 |
| **水面竿** | 波趴/铅笔 | ML-M、快调、精准控饵 | 水面系炸水 |

**设计优化（v4.2）**：

1. **饵类型使用字典表**：饵类型字段引用 `lure_types` 字典表，支持动态扩展
2. **专用竿属性放在鱼竿表**：`rod_specs.specialization_type`，因为"专用竿"是鱼竿的固有属性
3. **竿-饵适配度独立管理**：使用 `rod_lure_fitness` 表记录三档适配度（推荐/适合/勉强）

> **📌 关键关联表**：
> - **饵类型字典**：[lure_types](./02-00-字典表设计.md#2-饵类型字典表-lure_types) - 定义所有饵类型（支持层级）
> - **钓组类型字典**：[rig_types](./02-00-字典表设计.md#3-钓组类型字典表-rig_types) - 定义所有钓组类型
> - **竿-饵适配度**：[rod_lure_fitness](./02-00-字典表设计.md#4-竿-饵钓组适配度表-rod_lure_fitness) - 记录适配关系

详见 [鱼竿表设计 - 专用竿标识](./02-01-鱼竿表设计.md#-专用竿标识v41新增v42优化) 和 [字典表设计](./02-00-字典表设计.md)。

### 1.6 关系说明

| 关系 | 类型 | 说明 |

| 鱼种匹配 | 关联表 | lure_target_fish |

## 2. 硬饵表 (hard_bait_specs)

### 2.1 表结构定义

硬饵包括：米诺(Minnow)、胖子(Crankbait)、波趴(Popper)、铅笔(Pencil)、VIB、多节饵(Swimbait)、抽停饵(Jerkbait)等。

```sql
CREATE TABLE hard_bait_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id

    -- ═══════════════════════════════════════════════════════════
    -- 🏷️ 分类体系（8字段）
    -- 📌 类型字段引用 lure_types 字典表，支持动态扩展
    -- ═══════════════════════════════════════════════════════════
    lure_type_id TEXT NOT NULL,        -- 引用 lure_types.id：'minnow', 'crankbait', 'popper' 等
    sub_type_id TEXT,                  -- 引用 lure_types.id（子类型，如 'floating_minnow'）
    buoyancy_type TEXT NOT NULL CHECK(buoyancy_type IN (
        '浮水', '悬停', '沉水', '缓沉', '快沉'
    )),
    swimming_layer TEXT CHECK(swimming_layer IN (
        '水面', '浅层', '中层', '深层', '全泳层'
    )),
    technique_type TEXT,               -- 钓法类型（JSON数组）: '["抽停", "匀收", "慢摇"]'
    target_species TEXT,               -- 目标鱼种（JSON数组）: '["鲈鱼", "翘嘴", "鳜鱼"]'
    water_type TEXT CHECK(water_type IN ('淡水', '海水', '通用')),
    season_suitable TEXT,              -- 适用季节（JSON数组）: '["春", "秋"]'

    -- ═══════════════════════════════════════════════════════════
    -- 📏 物理规格（10字段）
    -- ═══════════════════════════════════════════════════════════
    length_mm REAL NOT NULL CHECK(length_mm > 0 AND length_mm < 500),
    weight_g REAL NOT NULL CHECK(weight_g > 0 AND weight_g < 200),
    weight_oz TEXT,                    -- 盎司表示（保留原始值）: "1/2oz"
    diving_depth_min_m REAL CHECK(diving_depth_min_m >= 0),
    diving_depth_max_m REAL CHECK(diving_depth_max_m >= diving_depth_min_m),
    diving_depth_raw TEXT,             -- 原始潜深描述: "1.5-2.5m"
    body_shape TEXT CHECK(body_shape IN (
        '细长', '标准', '肥短', '扁平', '圆柱'
    )),
    body_material TEXT DEFAULT '塑料' CHECK(body_material IN (
        '塑料', 'ABS', '木质', '树脂', '复合材料'
    )),
    is_jointed BOOLEAN DEFAULT FALSE,  -- 是否多节
    joints_count INTEGER CHECK(joints_count BETWEEN 1 AND 10),

    -- ═══════════════════════════════════════════════════════════
    -- 🔧 结构参数（10字段）
    -- ═══════════════════════════════════════════════════════════
    lip_type TEXT CHECK(lip_type IN (
        '无', '方舌', '圆舌', '长舌', '金属舌', '可调舌板'
    )),
    lip_material TEXT CHECK(lip_material IN (
        '塑料', '金属', '碳纤维', '聚碳酸酯'
    )),
    lip_angle TEXT CHECK(lip_angle IN ('平', '小角度', '中角度', '大角度')),
    weight_transfer_system TEXT CHECK(weight_transfer_system IN (
        '固定重心', '磁力转移', '柱塞式', '滚珠式', '钢珠转移', '无'
    )),
    sound_type TEXT CHECK(sound_type IN (
        '静音', '响珠', '单珠', '多珠', '金属撞击', '低频', '高频'
    )),
    rattle_material TEXT,              -- 响珠材质: '钢珠', '玻璃珠', '钨珠'
    internal_structure TEXT,           -- 内部结构描述
    eye_type TEXT CHECK(eye_type IN (
        '3D眼', '平面眼', '全息眼', '反光眼', '无'
    )),
    tail_type TEXT,                    -- 尾部类型（硬饵通常固定，软尾除外）
    special_features TEXT,             -- 特殊功能（JSON数组）: '["LED发光", "换色涂装"]'

    -- ═══════════════════════════════════════════════════════════
    -- 🌊 动作特性（8字段）
    -- ═══════════════════════════════════════════════════════════
    action_type TEXT NOT NULL CHECK(action_type IN (
        'Wobble', 'Roll', 'Wobble+Roll', 'S-Glide', 'Dog-Walk',
        'Dart', 'Spiral', 'Vibration', 'Pop', '复合动作'
    )),
    action_intensity TEXT CHECK(action_intensity IN (
        '微弱', '轻柔', '中等', '强烈', '暴力'
    )),
    action_frequency TEXT CHECK(action_frequency IN (
        '低频', '中频', '高频', '超高频'
    )),
    wobble_angle_deg REAL CHECK(wobble_angle_deg BETWEEN 0 AND 90),
    roll_angle_deg REAL CHECK(roll_angle_deg BETWEEN 0 AND 90),
    optimal_retrieve_speed TEXT CHECK(optimal_retrieve_speed IN (
        '极慢', '慢', '中速', '快', '极快', '变速'
    )),
    fall_action TEXT,                  -- 下落姿态: '平落', '头朝下', '螺旋', '飘落'
    action_description TEXT,           -- 动作详细描述

    -- ═══════════════════════════════════════════════════════════
    -- 🎨 外观工艺（6字段）
    -- ═══════════════════════════════════════════════════════════
    paint_tech TEXT CHECK(paint_tech IN (
        '哑光', '亮光', '电镀', '镭射', '透明', '夜光', 'UV', '热感变色'
    )),
    color_pattern TEXT,                -- 配色名称: "幽灵香鱼", "红头白身"
    color_category TEXT CHECK(color_category IN (
        '自然色', '亮色', '暗色', '透明', '夜光', '金属色'
    )),
    finish_type TEXT,                  -- 表面处理: '鳞片纹理', '光滑', '磨砂'
    has_uv_coating BOOLEAN DEFAULT FALSE,
    has_glow BOOLEAN DEFAULT FALSE,

    -- ═══════════════════════════════════════════════════════════
    -- 🪝 钩系统（6字段）
    -- ═══════════════════════════════════════════════════════════
    hook_count INTEGER CHECK(hook_count BETWEEN 0 AND 4),
    hook_type TEXT CHECK(hook_type IN ('三本钩', '单钩', '双钩', '无钩')),
    hook_size TEXT,                    -- 钩号: "#6", "#8", "1/0"
    hook_brand TEXT,                   -- 钩品牌: "BKK", "Owner", "Gamakatsu"
    hook_position TEXT,                -- 钩位置（JSON）: '["腹部", "尾部"]'
    split_ring_size TEXT,              -- 连接环规格

    -- ═══════════════════════════════════════════════════════════
    -- ⭐ 性能评分（1-10分，6字段）
    -- ═══════════════════════════════════════════════════════════
    casting_score INTEGER CHECK(casting_score BETWEEN 1 AND 10),
    action_quality_score INTEGER CHECK(action_quality_score BETWEEN 1 AND 10),
    durability_score INTEGER CHECK(durability_score BETWEEN 1 AND 10),
    hook_sharpness_score INTEGER CHECK(hook_sharpness_score BETWEEN 1 AND 10),
    value_score INTEGER CHECK(value_score BETWEEN 1 AND 10),
    overall_score REAL GENERATED ALWAYS AS (
        (COALESCE(casting_score, 5) * 0.2 +
         COALESCE(action_quality_score, 5) * 0.35 +
         COALESCE(durability_score, 5) * 0.2 +
         COALESCE(hook_sharpness_score, 5) * 0.1 +
         COALESCE(value_score, 5) * 0.15)
    ) STORED,

    -- ═══════════════════════════════════════════════════════════
    -- 💰 商业信息（5字段）
    -- ═══════════════════════════════════════════════════════════
    msrp_cny REAL CHECK(msrp_cny > 0),
    price_range TEXT,                  -- 价格区间: "50-80"
    purchase_link TEXT,                -- 购买链接
    release_year INTEGER CHECK(release_year BETWEEN 1990 AND 2030),
    is_discontinued BOOLEAN DEFAULT FALSE,

    -- ═══════════════════════════════════════════════════════════
    -- 📦 扩展字段
    -- ═══════════════════════════════════════════════════════════
    benchmark_products TEXT,           -- 对标竞品（JSON）: '["Smith D-Contact", "Duo Ryuki"]'
    design_notes TEXT,                 -- 设计说明/卖点
    user_tips TEXT,                    -- 使用技巧

    -- 外键约束
    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE,
    FOREIGN KEY (lure_type_id) REFERENCES lure_types(id),
    FOREIGN KEY (sub_type_id) REFERENCES lure_types(id)
);
```

### 2.2 分类体系详解

#### 硬饵类型引用（lure_type_id）

硬饵类型通过 `lure_type_id` 引用 `lure_types` 字典表，支持动态扩展。

常用硬饵类型ID：

| lure_type_id | name_cn | name_en | 典型特征 | 典型泳层 |
|--------------|---------|---------|----------|----------|
| `minnow` | 米诺 | Minnow | 细长鱼形，有舌板 | 浅-深层 |
| `crankbait` | 胖子 | Crankbait | 肥短体型，强烈摆动 | 浅-深层 |
| `popper` | 波趴 | Popper | 凹口设计，撞水声 | 水面 |
| `pencil` | 铅笔 | Pencil Bait | 细长无舌板，之字步 | 水面/沉水 |
| `vib` | VIB | Vibration | 扁平无舌板，高频震动 | 全泳层 |
| `swimbait` | 多节饵 | Swimbait | 多节连接，S形游动 | 中-深层 |
| `jerkbait` | 抽停饵 | Jerkbait | 长条悬停，抽停动作 | 浅-中层 |

#### 子类型引用（sub_type_id）

子类型同样引用 `lure_types` 字典表，通过 `parent_id` 建立层级关系。

常用子类型ID示例：

| sub_type_id | name_cn | parent_id |
|-------------|---------|-----------|
| `floating_minnow` | 浮水米诺 | `minnow` |
| `suspending_minnow` | 悬停米诺 | `minnow` |
| `sinking_minnow` | 沉水米诺 | `minnow` |
| `square_bill` | 方舌胖子 | `crankbait` |
| `deep_crank` | 深潜胖子 | `crankbait` |

> **📌 完整类型列表**：参见 [字典表设计 - 饵类型初始数据](./02-00-字典表设计.md#71-饵类型初始数据)

## 3. 软饵表 (soft_bait_specs)

### 3.1 表结构定义

软饵包括：T尾/鱼型、蠕虫类、虾蟹类、雷蛙等。

```sql
CREATE TABLE soft_bait_specs (
    equipment_id TEXT PRIMARY KEY,     -- 关联equipment.id

    -- ═══════════════════════════════════════════════════════════
    -- 🏷️ 分类体系（6字段）
    -- 📌 类型字段引用 lure_types 字典表，支持动态扩展
    -- ═══════════════════════════════════════════════════════════
    lure_type_id TEXT NOT NULL,        -- 引用 lure_types.id：'t_tail', 'craw', 'frog' 等
    sub_type_id TEXT,                  -- 引用 lure_types.id（子类型）
    tail_type TEXT CHECK(tail_type IN (
        'T尾', '卷尾', '针尾', '分叉尾', '飘带尾', '蛙腿', '螯足', '无尾'
```

## 7. SQL查询示例

### 7.1 基础查询

#### 查询特定类型的硬饵
```python
def search_hard_baits(
    self,
    lure_type_id: Optional[str] = None,  # 引用 lure_types.id
    buoyancy_type: Optional[str] = None,
    weight_min: Optional[float] = None,
    weight_max: Optional[float] = None,
    depth_max: Optional[float] = None,
    limit: int = 20
):
    """查询硬饵（v4.2更新：使用lure_type_id引用字典表）"""
    conn = self._get_connection()
    cursor = conn.cursor()

    query = '''
        SELECT e.*, h.*, lt.name_cn as lure_type_name, b.reputation_score
        FROM equipment e
        JOIN hard_bait_specs h ON e.id = h.equipment_id
        JOIN lure_types lt ON h.lure_type_id = lt.id
        LEFT JOIN brands b ON e.brand = b.brand_name
        WHERE 1=1
    '''
    params = []

    if lure_type_id:
        query += ' AND h.lure_type_id = ?'
        params.append(lure_type_id)

    if buoyancy_type:
        query += ' AND h.buoyancy_type = ?'
        params.append(buoyancy_type)

    if weight_min:
        query += ' AND h.weight_g >= ?'
        params.append(weight_min)

    if weight_max:
        query += ' AND h.weight_g <= ?'
        params.append(weight_max)

    if depth_max:
        query += ' AND h.diving_depth_max_m <= ?'
        params.append(depth_max)

    query += ' ORDER BY h.overall_score DESC LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

```python
        SELECT
            e.id, e.name, e.brand,
            r.power, r.action, r.length,
            r.lure_weight_min_g, r.lure_weight_max_g,
            rlf.fitness_level,
            rlf.notes,
            lt.name_cn as lure_type_name
        FROM equipment e
        JOIN rod_specs r ON e.id = r.equipment_id
        JOIN rod_lure_fitness rlf ON e.id = rlf.rod_equipment_id
        JOIN lure_types lt ON rlf.lure_type_id = lt.id
        WHERE rlf.lure_type_id = ?
    '''
    params = [lure_type_id]

    if fitness_level:
        query += ' AND rlf.fitness_level = ?'
        params.append(fitness_level)

    query += ' ORDER BY rlf.fitness_level ASC, e.name LIMIT ?'
    params.append(limit)

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```

```python
def get_rod_fitness_profile(self, rod_equipment_id: str):
    """获取鱼竿的完整适配度档案（v4.2更新）"""
    conn = self._get_connection()
    cursor = conn.cursor()

    # 查询饵类型适配度
    cursor.execute('''
        SELECT
            lt.id, lt.name_cn, lt.name_en, lt.category,
            rlf.fitness_level, rlf.notes
        FROM rod_lure_fitness rlf
        JOIN lure_types lt ON rlf.lure_type_id = lt.id
        WHERE rlf.rod_equipment_id = ?
        ORDER BY lt.category, lt.sort_order
    ''', (rod_equipment_id,))
    lure_fitness = [dict(row) for row in cursor.fetchall()]

    # 查询钓组适配度
    cursor.execute('''
        SELECT
            rt.id, rt.name_cn, rt.name_en,
            rlf.fitness_level, rlf.notes
        FROM rod_lure_fitness rlf
        JOIN rig_types rt ON rlf.rig_type_id = rt.id
        WHERE rlf.rod_equipment_id = ?
        ORDER BY rt.sort_order
    ''', (rod_equipment_id,))
    rig_fitness = [dict(row) for row in cursor.fetchall()]

    return {
        'rod_id': rod_equipment_id,
        'lure_fitness': lure_fitness,
        'rig_fitness': rig_fitness
    }
```

### 7.4 综合装备搭配

#### 根据场景推荐完整装备
```python
def recommend_tackle_setup(
    self,
    scenario: str,
    target_fish: str,
    budget_max: Optional[float] = None
):
    """根据场景推荐完整装备搭配"""
    conn = self._get_connection()
    cursor = conn.cursor()

    # 1. 查询适合该场景的鱼饵
    cursor.execute('''
        SELECT
            e.*,
            COALESCE(h.hard_bait_type, s.soft_bait_type, m.metal_bait_type) as lure_type,
            COALESCE(h.weight_g, s.weight_g, m.weight_g) as lure_weight,
            lsm.effectiveness_score as scenario_score,
            ltf.effectiveness_score as fish_score
        FROM equipment e
        LEFT JOIN hard_bait_specs h ON e.id = h.equipment_id
        LEFT JOIN soft_bait_specs s ON e.id = s.equipment_id
        LEFT JOIN metal_bait_specs m ON e.id = m.equipment_id
        LEFT JOIN lure_scenario_match lsm ON (
            lsm.lure_equipment_id = e.id OR lsm.lure_type = COALESCE(h.hard_bait_type, s.soft_bait_type, m.metal_bait_type)
        )
        LEFT JOIN lure_target_fish ltf ON (
            ltf.lure_equipment_id = e.id OR ltf.lure_type = COALESCE(h.hard_bait_type, s.soft_bait_type, m.metal_bait_type)
        )
        WHERE lsm.scenario_type = ?
          AND ltf.fish_species = ?
        ORDER BY (COALESCE(lsm.effectiveness_score, 5) + COALESCE(ltf.effectiveness_score, 5)) DESC
        LIMIT 5
    ''', (scenario, target_fish))

    recommended_lures = [dict(row) for row in cursor.fetchall()]

    # 2. 为每个推荐的鱼饵找匹配的鱼竿
    results = []
    for lure in recommended_lures:
        rods = self.find_rods_for_lure(lure['id'], include_specialized=True)
        if budget_max:
            rods = [r for r in rods if r.get('price_min', 0) <= budget_max]

        results.append({
            'lure': lure,
            'recommended_rods': rods[:3],  # 取前3个推荐
            'setup_notes': f"场景评分: {lure.get('scenario_score', 'N/A')}, 鱼种匹配: {lure.get('fish_score', 'N/A')}"
        })

    return results
```

**使用示例**：
```python
# 草区打黑装备推荐

    scenario='草区',
    target_fish='黑鱼',
    budget_max=1000
)

# 明水路亚鲈鱼装备推荐
setup = db.recommend_tackle_setup(
    scenario='明水',
    target_fish='鲈鱼',
    budget_max=800
)
```

### 7.5 按钓组查询软饵

```python
def search_soft_baits_by_rig(
    self,
    rig_type: str,  # 'texas', 'carolina', 'drop_shot', 'neko', 'wacky', 'jig_head', 'weightless'
    min_length: Optional[float] = None,
    max_length: Optional[float] = None
):
    """按钓组类型查询软饵"""
    conn = self._get_connection()
    cursor = conn.cursor()

    rig_column_map = {
        'texas': 'texas_rig',
        'carolina': 'carolina_rig',
        'drop_shot': 'drop_shot_rig',
        'neko': 'neko_rig',
        'wacky': 'wacky_rig',
        'jig_head': 'jig_head',
        'weightless': 'weightless',
        'free': 'free_rig'
    }

    column = rig_column_map.get(rig_type)
    if not column:
        return []

    query = f'''
        SELECT e.*, s.*
        FROM equipment e
        JOIN soft_bait_specs s ON e.id = s.equipment_id
        WHERE s.{column} = TRUE
    '''
    params = []

    if min_length:
        query += ' AND s.length_mm >= ?'
        params.append(min_length)

    if max_length:
        query += ' AND s.length_mm <= ?'
        params.append(max_length)

    query += ' ORDER BY s.overall_score DESC'

    cursor.execute(query, params)
    return [dict(row) for row in cursor.fetchall()]
```
