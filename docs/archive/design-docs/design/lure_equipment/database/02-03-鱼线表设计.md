## 设计概述

### 设计目标

本数据库设计旨在支持以下核心功能：

1. **精准线组选购**：基于线型、强度、使用场景的智能推荐
2. **科学线组搭配**：主线+前导线的最优配比计算
3. **专业参数管理**：70个核心字段覆盖所有线组参数
4. **商业化功能**：多规格价格管理、购买链接、库存状态

### 表结构概览

鱼线相关表共3个：

| 表名 | 说明 | 记录数量级 |
|------|------|------------|
| **line_specs** | 鱼线规格主表（核心表，70字段） | ~300+ |
| **line_capacity_variants** | 长度规格关联表（价格/库存） | ~1000+ |
| **line_combo_recommendations** | 线组搭配推荐表 | ~500+ |

**关系说明**：

| 关系 | 类型 | 说明 |
|------|------|------|
| equipment → line_specs | 1:1 | 每款鱼线装备对应一条规格记录 |
| line_specs → line_capacity_variants | 1:N | 同一型号鱼线可有多种长度规格（100m/150m/300m） |
| line_specs → line_combo_recommendations | N:N | 主线与前导线的多对多搭配关系 |

**数据分层策略**：

| 数据类型 | 存储方式 | 原因 |
|----------|----------|------|
| 核心性能参数 | 独立字段 | 强度、线径、比重等需要范围查询和精确筛选 |
| 多规格价格 | 关联表 | 同型号不同长度的价格/库存独立管理 |
| 搭配关系 | 关联表 | 主线+前导线的科学配比需要多对多关系 |
| 适用场景 | JSON字段 | 目标鱼种、钓法、优缺点等灵活扩展 |

**线型特性对比**：

| 线型 | 比重 | 延展性 | 透明度 | 耐磨性 | 主要用途 |
|------|------|--------|--------|--------|----------|
| **PE线** | 0.97 (浮) | 低 (<3%) | 差 | 中 | 主线 |
| **尼龙线** | 1.14 (慢沉) | 高 (20-30%) | 中 | 差 | 入门主线/缓冲 |
| **碳线** | 1.78 (快沉) | 低 (10-15%) | 优 | 优 | 前导线 |
| **钢丝** | 7.8+ (极沉) | 无 | 差 | 极优 | 防咬前导 |

## 表结构设计

### 主表: line_specs

**核心鱼线规格表** - 存储所有路亚鱼线的详细参数（70个字段）

```sql
CREATE TABLE line_specs (
    -- ==================== 基础信息 (10字段) ====================
    equipment_id TEXT PRIMARY KEY,                    -- 装备ID (外键关联 equipment.id)
    brand TEXT NOT NULL,                              -- 品牌 (VARIVAS/DAIWA/SHIMANO...)
    model TEXT NOT NULL,                              -- 型号 (AVANI GT/UVF SALTIGA...)
    series TEXT,                                      -- 系列名 (GT系列/船钓系列)
    line_type TEXT NOT NULL CHECK(line_type IN (
        'PE', '尼龙', '碳线', '钢丝', 'PE混编'
    )),                                               -- 线型 (核心分类)
    color TEXT,                                       -- 颜色 (白色/荧光绿/透明)
    production_country TEXT,                          -- 产地 (日本/中国/美国)
    release_year INTEGER CHECK(release_year >= 2000), -- 发布年份
    discontinued BOOLEAN DEFAULT 0,                   -- 是否停产
    legacy_specs_json TEXT,                           -- 历史遗留specs_json (向后兼容)

    -- ==================== 核心规格参数 (14字段) ====================
    -- 强度参数 (号数/磅数)
    strength_raw TEXT,                                -- 原始强度标注 (如 "2.0号" "20LB")
    strength_number REAL CHECK(strength_number > 0),  -- 号数 (日标, 0.4-10号)
    strength_lbs REAL CHECK(strength_lbs > 0),        -- 磅数 (6-100LB)
    strength_kg REAL CHECK(strength_kg > 0),          -- 公斤数 (自动换算)

    -- 线径参数
    diameter_raw TEXT,                                -- 原始线径标注 (如 "0.148mm")
    diameter_mm REAL CHECK(diameter_mm > 0 AND diameter_mm < 2.0), -- 线径毫米数

    -- 长度参数
    default_length_m INTEGER NOT NULL DEFAULT 150,    -- 默认长度 (米)
    length_variants TEXT,                             -- 可选长度规格 (JSON: [100,150,300,500])

    -- 拉力参数 (核心!)
    straight_pull_strength_lbs REAL,                  -- 直线拉力 (磅数, 标称值)
    straight_pull_strength_kg REAL,                   -- 直线拉力 (公斤数)
    knot_strength_lbs REAL,                           -- 结节拉力 (磅数, 实测值)
    knot_strength_kg REAL,                            -- 结节拉力 (公斤数)
    knot_strength_retention_rate REAL CHECK(
        knot_strength_retention_rate BETWEEN 0 AND 100
    ),                                                -- 结节强度保持率 (60-95%)
    test_conditions TEXT,                             -- 测试条件说明 (干燥/25°C/GT结)

    -- 比重 (浮沉性判断)
    specific_gravity REAL CHECK(specific_gravity > 0 AND specific_gravity < 3.0), -- 比重 (0.9-1.8)

    -- ==================== PE线专有字段 (8字段) ====================
    braid_count INTEGER CHECK(braid_count IN (4, 8, 12, 16)), -- 编织数 (4/8/12编)
    braid_density_score INTEGER CHECK(braid_density_score BETWEEN 1 AND 10), -- 编织紧密度 (1-10分)
    roundness_score INTEGER CHECK(roundness_score BETWEEN 1 AND 10), -- 圆滑度 (1-10分, 影响远投)
    hybrid_type TEXT CHECK(hybrid_type IN (
        '纯PE', 'PE+钢丝', 'PE+碳线', 'PE+尼龙芯'
    )),                                               -- 混编类型
    core_structure TEXT,                              -- 芯线结构描述 (如 "钢丝防咬芯")
    coating_type TEXT,                                -- 涂层类型 (硅油/蜡质/陶瓷)
    color_segment_length_m INTEGER,                   -- 分段变色长度 (10m/25m, 用于深度标记)
    uv_coating BOOLEAN DEFAULT 0,                     -- 是否有抗UV涂层

    -- ==================== 物理特性评分 (9字段, 1-10分量化) ====================
    flexibility_score INTEGER CHECK(flexibility_score BETWEEN 1 AND 10), -- 延展性 (PE:2 尼龙:9 碳线:5)
    abrasion_resistance_score INTEGER CHECK(abrasion_resistance_score BETWEEN 1 AND 10), -- 耐磨性 (PE:6 尼龙:4 碳线:10)
    water_cutting_score INTEGER CHECK(water_cutting_score BETWEEN 1 AND 10), -- 切水性 (PE:6 尼龙:9 碳线:10)
    transparency_score INTEGER CHECK(transparency_score BETWEEN 1 AND 10), -- 透明度 (PE:2 尼龙:6 碳线:10)
    water_absorption_rate REAL CHECK(water_absorption_rate BETWEEN 0 AND 100), -- 吸水率 (%, 尼龙5-8% PE<1%)
    memory_score INTEGER CHECK(memory_score BETWEEN 1 AND 10), -- 记忆性 (越低越好, PE:2 碳线:8)
    softness_score INTEGER CHECK(softness_score BETWEEN 1 AND 10), -- 柔软度 (尼龙:9 PE:7 碳线:4)
    wind_resistance_coefficient REAL CHECK(wind_resistance_coefficient > 0), -- 风阻系数 (线径相关)
    sinking_speed_score INTEGER CHECK(sinking_speed_score BETWEEN 1 AND 10), -- 沉降速度 (PE:3 尼龙:6 碳线:9)

    -- ==================== 材质信息 (7字段) ====================
    base_material TEXT,                               -- 基础材质 (聚乙烯/尼龙6/PVDF)
    material_composition TEXT,                        -- 材料成分详情 (如 "超高分子量聚乙烯")
    carbon_content REAL CHECK(carbon_content BETWEEN 0 AND 100), -- 碳含量 (%, 碳线用)
    fluorocarbon_content REAL CHECK(fluorocarbon_content BETWEEN 0 AND 100), -- 氟碳含量 (%)
    coating_material TEXT,                            -- 涂层材料 (硅油/陶瓷/纳米涂层)
    core_material TEXT,                               -- 芯线材料 (钢丝/碳纤维, PE混编用)
    dyeing_method TEXT,                               -- 染色方式 (原丝染色/表面染色)

    -- ==================== 使用场景 (13字段) ====================
    usage_as_main_line BOOLEAN DEFAULT 1,             -- 可作主线使用
    usage_as_leader BOOLEAN DEFAULT 0,                -- 可作前导线使用
    freshwater_suitable BOOLEAN DEFAULT 1,            -- 淡水适用
    saltwater_suitable BOOLEAN DEFAULT 0,             -- 海水适用
    saltwater_rating INTEGER CHECK(saltwater_rating BETWEEN 0 AND 10), -- 海水耐腐蚀等级 (0-10)
    water_type_compatibility TEXT CHECK(water_type_compatibility IN (
        '淡水', '海水', '通用'
    )),                                               -- 水域兼容性
    obstacle_environment TEXT CHECK(obstacle_environment IN (
        '开阔水面', '轻障碍', '中障碍', '重障碍', '极端障碍'
    )),                                               -- 障碍物环境适应
    target_species TEXT,                              -- 对象鱼种 (JSON格式)
    fishing_methods TEXT,                             -- 适用钓法 (JSON: 路亚/船钓/岸钓)
    best_season TEXT,                                 -- 最佳季节 (春/夏/秋/冬/全年)
    temperature_range_min INTEGER,                    -- 适用最低温度 (°C)
    temperature_range_max INTEGER,                    -- 适用最高温度 (°C)
    depth_range TEXT,                                 -- 作钓深度范围 (浅水/中层/深海)

    -- ==================== 性能指标 (9字段) ====================
    casting_performance_score INTEGER CHECK(casting_performance_score BETWEEN 1 AND 10), -- 远投性能 (1-10分)
    sensitivity_score INTEGER CHECK(sensitivity_score BETWEEN 1 AND 10), -- 灵敏度 (信号传递)
    durability_cycles INTEGER,                        -- 耐久性 (可承受抛投次数)
    uv_resistance_score INTEGER CHECK(uv_resistance_score BETWEEN 1 AND 10), -- 抗UV能力 (1-10分)
    low_temp_performance_score INTEGER CHECK(low_temp_performance_score BETWEEN 1 AND 10), -- 低温性能 (冬季)
    high_temp_performance_score INTEGER CHECK(high_temp_performance_score BETWEEN 1 AND 10), -- 高温性能 (夏季)
    knot_performance TEXT,                            -- 不同结法表现 (JSON格式)
    lifespan_months INTEGER,                          -- 预期寿命 (月)
    wear_indicator TEXT,                              -- 磨损标识 (变色/起毛/断股)

    -- ==================== JSON扩展字段 (7字段) ====================
    technical_features TEXT,                          -- 技术特点 (JSON: 核心技术说明)
    advantages TEXT,                                  -- 优点 (JSON数组)
    disadvantages TEXT,                               -- 缺点 (JSON数组)
    usage_tips TEXT,                                  -- 使用建议 (JSON: 操作要点)
    combo_recommendations TEXT,                       -- 搭配建议 (JSON: 主线+前导配比)
    purchase_links TEXT,                              -- 购买链接 (JSON格式)
    images TEXT,                                      -- 产品图片 (JSON: URL数组)

    -- ==================== 外键约束 ====================
    FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE
);
```

### 关联表1: line_capacity_variants

**多规格长度管理表** - 同一型号鱼线的不同长度规格（如 100m/150m/300m 的价格差异）

```sql
CREATE TABLE line_capacity_variants (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    line_id TEXT NOT NULL,                            -- 关联 line_specs.equipment_id
    length_m INTEGER NOT NULL CHECK(length_m > 0),    -- 长度 (米)
    price_cny REAL CHECK(price_cny >= 0),             -- 价格 (人民币)
    stock_status TEXT CHECK(stock_status IN (
        '现货', '预售', '缺货', '停产'
    )),                                               -- 库存状态
    weight_g REAL,                                    -- 重量 (克, 含包装)
    packaging_type TEXT,                              -- 包装类型 (卡装/盒装/轴装)
    release_date DATE,                                -- 上市日期
    discontinued_date DATE,                           -- 停产日期

    FOREIGN KEY (line_id) REFERENCES line_specs(equipment_id) ON DELETE CASCADE,
    UNIQUE(line_id, length_m)                         -- 同型号同长度唯一
);
```

### 关联表2: line_combo_recommendations

**线组搭配推荐表** - 科学的主线+前导线配比方案

```sql
CREATE TABLE line_combo_recommendations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    main_line_id TEXT NOT NULL,                       -- 主线ID (通常为PE线)
    leader_line_id TEXT NOT NULL,                     -- 前导线ID (通常为碳线)

    -- 配比参数
    combo_ratio REAL CHECK(combo_ratio > 0),          -- 配比倍数 (前导/主线, 通常2-2.5倍)
    main_strength_number REAL,                        -- 主线号数 (如 PE 1.0号)
    leader_strength_number REAL,                      -- 前导号数 (如 碳线 2.5号)

    -- 适用场景
    target_species TEXT,                              -- 目标鱼种 (JSON数组)
    fishing_scenario TEXT,                            -- 作钓场景 (开阔水面/障碍区/岩石区)
    lure_weight_range TEXT,                           -- 拟饵重量范围 (如 "7-21g")
    rod_power_range TEXT,                             -- 适配竿型 (ML-MH)

    -- 连接方法
    recommended_knot TEXT,                            -- 推荐结法 (GT结/FG结)
    connection_method TEXT,                           -- 连接方式 (直连/八字环)
    leader_length_cm INTEGER,                         -- 前导长度 (厘米, 50-150cm)

    -- 性能说明
    combo_strength_rating TEXT,                       -- 组合强度评级 (A+/A/B/C)
    balance_score INTEGER CHECK(balance_score BETWEEN 1 AND 10), -- 均衡性评分 (1-10)
    scenario_match_score INTEGER CHECK(scenario_match_score BETWEEN 1 AND 10), -- 场景适配度

    usage_notes TEXT,                                 -- 使用注意事项
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (main_line_id) REFERENCES line_specs(equipment_id) ON DELETE CASCADE,
    FOREIGN KEY (leader_line_id) REFERENCES line_specs(equipment_id) ON DELETE CASCADE,
    UNIQUE(main_line_id, leader_line_id)              -- 同组合唯一
);
```

## 字段详解

### 一、基础信息字段 (10字段)

| 字段名 | 类型 | 说明 | 示例 | 必填 |
|--------|------|------|------|------|
| equipment_id | TEXT | 装备唯一ID | `varivas_avani_gt_pe2.0_300m` | ✅ |
| brand | TEXT | 品牌名称 | `VARIVAS`, `DAIWA`, `SHIMANO` | ✅ |
| model | TEXT | 型号 | `AVANI GT`, `UVF SALTIGA` | ✅ |
| series | TEXT | 系列名 | `GT系列`, `船钓系列` | ❌ |
| line_type | TEXT | 线型分类 | `PE`, `尼龙`, `碳线`, `钢丝` | ✅ |
| color | TEXT | 颜色 | `荧光绿`, `白色`, `透明` | ❌ |
| production_country | TEXT | 产地 | `日本`, `中国`, `美国` | ❌ |
| release_year | INTEGER | 发布年份 | `2022` | ❌ |
| discontinued | BOOLEAN | 是否停产 | `0`(在产) `1`(停产) | ✅ |
| legacy_specs_json | TEXT | 历史JSON数据 | 向后兼容保留字段 | ❌ |

**设计说明**:
- `equipment_id` 作为主键，关联 `equipment` 主表
- `line_type` 是核心分类字段，直接影响其他专有字段的填充
- `color` 对PE线很重要（分段变色用于深度标记），对碳线次要（透明为主）

---

### 二、核心规格参数 (14字段)

#### 2.1 强度参数

| 字段名 | 类型 | 说明 | 取值范围 | 示例 |
|--------|------|------|----------|------|
| strength_raw | TEXT | 原始标注 | 任意字符串 | `"2.0号"`, `"20LB"`, `"9kg"` |
| strength_number | REAL | 号数(日标) | 0.4-10.0 | `1.5`, `2.0`, `3.0` |
| strength_lbs | REAL | 磅数 | 6-100 | `20.0`, `35.0`, `50.0` |
| strength_kg | REAL | 公斤数 | 自动换算 | `9.0`, `15.9`, `22.7` |

**换算关系**: `1 LB ≈ 0.4536 kg` | `1号 ≈ 4LB (仅参考，各品牌略有差异)`

**设计说明**:
- 保留 `strength_raw` 原始值，避免信息丢失
- 同时存储 号数/磅数/公斤数 三种单位，方便不同地区用户查询
- 号数主要用于日系品牌，磅数通用性更强

#### 2.2 线径参数

| 字段名 | 类型 | 说明 | 取值范围 | 示例 |
|--------|------|------|----------|------|
| diameter_raw | TEXT | 原始标注 | 任意字符串 | `"0.148mm"`, `"#0.6"` |
| diameter_mm | REAL | 线径毫米数 | 0.05-2.0mm | `0.148`, `0.235`, `0.405` |

**重要性**:
- 线径直接影响 **远投距离**（越细越远）
- 影响 **风阻**（细线抗风能力强）
- 影响 **容线量**（细线轮子可缠更多）

#### 2.3 长度参数

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| default_length_m | INTEGER | 默认长度(米) | `150` (最常见) |
| length_variants | TEXT | 可选规格(JSON) | `"[100, 150, 300, 500]"` |

**常见规格**:
- **100m**: 练习款/低价入门
- **150m**: 主流标准长度
- **300m**: 高性价比（单价更低）
- **500m+**: 专业船钓/商业捕捞

#### 2.4 拉力参数 (核心!)

| 字段名 | 类型 | 说明 | 典型差异 |
|--------|------|------|----------|
| straight_pull_strength_lbs | REAL | 直线拉力(磅) | PE线标称值 |
| straight_pull_strength_kg | REAL | 直线拉力(kg) | 换算值 |
| knot_strength_lbs | REAL | 结节拉力(磅) | **实战真实值** |
| knot_strength_kg | REAL | 结节拉力(kg) | 换算值 |

**评分标准**:
- **1-3分**: 差/不适合
- **4-6分**: 中等/可用

- **9-10分**: 优秀/完美

**应用场景匹配**:

## 索引设计

**9个索引，覆盖高频查询场景**

```sql
-- 1. 单字段索引: 线型 (最高频查询)
CREATE INDEX idx_line_type ON line_specs(line_type);

-- 2. 单字段索引: 品牌 (高频筛选)
CREATE INDEX idx_brand ON line_specs(brand);

-- 3. 复合索引: 线型+号数 (常见组合查询 "PE 1.5号")
CREATE INDEX idx_line_type_strength ON line_specs(line_type, strength_number);

-- 4. 复合索引: 线型+拉力范围 (按拉力筛选)
CREATE INDEX idx_line_type_pull_strength ON line_specs(line_type, straight_pull_strength_lbs);

-- 5. 复合索引: 线型+主线/前导 (场景匹配)
CREATE INDEX idx_line_usage ON line_specs(line_type, usage_as_main_line, usage_as_leader);

-- 6. 复合索引: 水域类型+障碍物环境 (场景推荐)
CREATE INDEX idx_water_obstacle ON line_specs(water_type_compatibility, obstacle_environment);

-- 7. 单字段索引: 结节强度保持率 (性能排序)
CREATE INDEX idx_knot_retention ON line_specs(knot_strength_retention_rate DESC);

-- 8. 单字段索引: 耐磨性评分 (障碍区专用)
CREATE INDEX idx_abrasion_resistance ON line_specs(abrasion_resistance_score DESC);

-- 9. 单字段索引: 透明度评分 (高压力水域)
CREATE INDEX idx_transparency ON line_specs(transparency_score DESC);
```

**索引使用场景**:

| 索引 | 查询场景 | SQL示例 |
|------|----------|---------|
| idx_line_type | 查看所有PE线 | `WHERE line_type = 'PE'` |
| idx_line_type_strength | 查找PE 1.5号 | `WHERE line_type = 'PE' AND strength_number = 1.5` |
| idx_line_type_pull_strength | 拉力20-30LB的PE线 | `WHERE line_type = 'PE' AND straight_pull_strength_lbs BETWEEN 20 AND 30` |
| idx_line_usage | 适合做前导的碳线 | `WHERE line_type = '碳线' AND usage_as_leader = 1` |
| idx_water_obstacle | 淡水重障碍区用线 | `WHERE water_type_compatibility = '淡水' AND obstacle_environment = '重障碍'` |
| idx_knot_retention | 结节强度最高的线 | `ORDER BY knot_strength_retention_rate DESC LIMIT 10` |
| idx_abrasion_resistance | 最耐磨的线 | `WHERE abrasion_resistance_score >= 9` |
| idx_transparency | 最隐形的线 | `WHERE transparency_score >= 9` |

```sql
    e.brand,
    e.model,
    ls.strength_number,
    ls.straight_pull_strength_lbs,
    ls.knot_strength_lbs,
    ls.knot_strength_retention_rate,
    ls.casting_performance_score
```

## 线组搭配算法

### 科学配比原理

**核心公式**:
```
前导线号数 = 主线号数 × 配比系数 (2.0~2.5)

条件约束:
  - 主线结节拉力 ≈ 前导线结节拉力 (误差±10%)
  - 主线线径 < 前导线线径 (确保先断前导)
  - 前导线耐磨性 > 主线耐磨性 (保护主线)
```

### 配比计算示例

#### 示例1: PE 1.0号 + 碳线前导

```python
# 主线参数
main_line = {
    "type": "PE",
    "strength_number": 1.0,
    "straight_pull_lbs": 22,
    "knot_strength_lbs": 15.4,  # 70%保持率
    "knot_retention_rate": 0.70
}

# 计算前导线需求
leader_target_strength = main_line["knot_strength_lbs"]  # 15.4 LB
leader_retention_rate = 0.80  # 碳线典型保持率

# 反推前导线直线拉力
leader_straight_pull = leader_target_strength / leader_retention_rate
# = 15.4 / 0.80 = 19.25 LB

# 选择碳线 2.5号 (18-20LB) ✅ 匹配
leader_line = {
    "strength_number": 2.5,
    "straight_pull_lbs": 18,
    "knot_strength_lbs": 14.8  # 误差 4% 可接受
}

# 配比倍数
ratio = leader_line["strength_number"] / main_line["strength_number"]
# = 2.5 / 1.0 = 2.5 ✅ 符合2-2.5倍标准
```


**商业价值**:

### 5. 多规格长度管理 ⭐

**同型号不同长度的价格/库存独立管理**

```sql
-- 同型号多规格 (100m/150m/300m)
CREATE TABLE line_capacity_variants (
    line_id TEXT,
    length_m INTEGER,
    price_cny REAL,
    stock_status TEXT
);
```

**解决问题**:
- ✅ 100m入门款 vs 300m性价比款定价差异
- ✅ 库存管理 (某规格缺货不影响其他规格)
- ✅ 促销活动 (针对特定规格降价)

**查询示例**:
```sql
-- 对比同型号不同规格性价比
SELECT
    length_m,
    price_cny,
    ROUND(price_cny / length_m, 2) AS price_per_meter
FROM line_capacity_variants
WHERE line_id = 'varivas_avani_gt_pe2.0'
ORDER BY price_per_meter;
```

### 7. 数据完整性保障

**多层约束确保数据质量**

```sql
-- 1. CHECK约束 (数值合理性)
CHECK(diameter_mm > 0 AND diameter_mm < 2.0)
CHECK(knot_strength_retention_rate BETWEEN 0 AND 100)

-- 2. 枚举约束 (分类准确性)
CHECK(line_type IN ('PE', '尼龙', '碳线', '钢丝'))

-- 3. 外键约束 (关联一致性)
FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE CASCADE

-- 4. 唯一约束 (防重复)
UNIQUE(line_id, length_m)  -- line_capacity_variants表
```
