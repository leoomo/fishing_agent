## 🎯 算法目标

### 核心目标
1. **准确性**：推荐结果与用户需求高度匹配（>85%相关度）
2. **可解释性**：用户能理解为什么推荐这款装备
3. **可配置性**：权重可调整，支持A/B测试
4. **性能**：推荐计算<100ms

### 非目标
- ❌ 个性化推荐（数据量不足）
- ❌ 机器学习（过度设计）
- ❌ 实时学习（无用户行为数据）

---

## 📊 推荐算法架构

### 四维度评分模型

```
总分 = 价格匹配分(35%) + 规格匹配分(35%) + 品牌信誉分(15%) + 用户水平分(15%)
```

**权重设计理由**：
- **价格35%**：预算是硬约束，用户最关心
- **规格35%**：技术参数决定适用性
- **品牌15%**：信誉背书，降低决策风险
- **用户水平15%**：新手/进阶/专业需求不同

## 🔢 评分算法详解

### 1. 价格匹配评分（35%）

**算法**：
```python
def calculate_price_score(equipment: Dict, user_budget: float) -> float:
    """
    价格匹配度评分

    规则：
    - 价格 <= 预算：得分100分
    - 预算 < 价格 <= 预算*1.2：线性递减到60分
    - 价格 > 预算*1.2：0分（直接过滤）

    Args:
        equipment: 装备数据 {"price_min": 650, "price_max": 750}
        user_budget: 用户预算（如300）

    Returns:
        0.0-1.0的评分
    """
    price = equipment.get('price_min', 0)

    if price <= user_budget:
        # 价格越低越好（但不能太便宜）
        if price < user_budget * 0.3:
            return 0.6  # 太便宜可能质量差
        else:
            return 1.0 - (user_budget - price) / user_budget * 0.4

    elif price <= user_budget * 1.2:
        # 允许超预算20%，线性递减
        overflow_ratio = (price - user_budget) / (user_budget * 0.2)
        return 0.6 - overflow_ratio * 0.6

    else:
        # 超预算太多，直接过滤
        return 0.0
```

**示例**：
```
用户预算：¥300

装备A：¥250  → 评分 = 0.87（略低于预算，性价比高）
装备B：¥300  → 评分 = 1.00（刚好预算）
装备C：¥330  → 评分 = 0.30（超预算10%，可接受）
装备D：¥400  → 评分 = 0.00（超预算33%，过滤）
```

### 2. 规格匹配评分（35%）

**算法**：多维度匹配 + 容差处理

```python
def calculate_spec_score(equipment: Dict, user_specs: Dict, config: Dict) -> float:
    """
    规格匹配度评分

    考虑因素：
    1. 硬度匹配（鱼竿）
    2. 长度匹配（鱼竿）
    3. 型号匹配（渔轮）
    4. 材质匹配（鱼线）

    Returns:
        0.0-1.0的评分
    """
    specs = equipment.get('specs', {})
    category = equipment.get('category')
    tolerance = config['filters']['spec_tolerance']

    scores = []

    # 1. 硬度匹配（鱼竿专用）
    if category == '鱼竿' and 'power' in user_specs:
        power_score = _match_power(
            specs.get('power'),
            user_specs['power'],
            tolerance.get('power', 1)
        )
        scores.append(power_score)

    # 2. 长度匹配（鱼竿专用）
    if category == '鱼竿' and 'length' in user_specs:
        length_score = _match_length(
            specs.get('length'),
            user_specs['length'],
            tolerance.get('length', 0.3)
        )
        scores.append(length_score)

    # 3. 调性匹配（鱼竿专用）
    if category == '鱼竿' and 'action' in user_specs:
        if specs.get('action') == user_specs['action']:
            scores.append(1.0)
        else:
            scores.append(0.5)

    # 4. 型号匹配（渔轮专用）
    if category == '渔轮' and 'model' in user_specs:
        if user_specs['model'] in specs.get('model', ''):
            scores.append(1.0)
        else:
            scores.append(0.5)

    # 返回平均分
    return sum(scores) / len(scores) if scores else 0.7


def _match_power(equipment_power: str, user_power: str, tolerance: int) -> float:
    """
    硬度匹配（带容差）

    硬度等级：UUL(0) < UL(1) < L(2) < ML(3) < M(4) < MH(5) < H(6) < XH(7) < XXH(8)

    容差规则：
    - 完全匹配：1.0分
    - 相差1档（如ML和M）：0.8分
    - 相差2档：0.5分
    - 相差>2档：0.0分

    Args:
        equipment_power: 装备硬度（如"ML"）
        user_power: 用户需求硬度（如"ML"）
        tolerance: 允许的档位差（默认1）

    Returns:
        0.0-1.0的评分
    """
    power_levels = {
        'UUL': 0, 'UL': 1, 'L': 2, 'ML': 3, 'M': 4,
        'MH': 5, 'H': 6, 'XH': 7, 'XXH': 8
    }

    equip_level = power_levels.get(equipment_power, 4)
    user_level = power_levels.get(user_power, 4)

    diff = abs(equip_level - user_level)

    if diff == 0:
        return 1.0
    elif diff <= tolerance:
        return 0.8
    elif diff <= tolerance * 2:
        return 0.5
    else:
        return 0.0


def _match_length(equipment_length: float, user_length: float, tolerance: float) -> float:
    """
    长度匹配（带容差）

    容差规则：
    - 误差 <= tolerance(0.3米)：1.0分
    - 0.3米 < 误差 <= 0.6米：0.6分
    - 误差 > 0.6米：0.0分

    Args:
        equipment_length: 装备长度（如2.64）
        user_length: 用户需求长度（如2.4）
        tolerance: 允许误差（默认0.3米）

    Returns:
        0.0-1.0的评分
    """
    diff = abs(equipment_length - user_length)

    if diff <= tolerance:
        return 1.0
    elif diff <= tolerance * 2:
        return 0.6
    else:
        return 0.0
```

**示例**：
```
用户需求：ML调 2.4米鱼竿

装备A：ML 2.4m  → 硬度1.0 + 长度1.0 = 1.00（完美匹配）
装备B：M  2.4m  → 硬度0.8 + 长度1.0 = 0.90（硬度差1档）
装备C：ML 2.7m  → 硬度1.0 + 长度0.6 = 0.80（长度差0.3米）
装备D：MH 3.0m  → 硬度0.5 + 长度0.0 = 0.25（差距较大）
```

### 3. 品牌信誉评分（15%）

**算法**：基于品牌等级的固定评分

```python
def calculate_brand_score(equipment: Dict, brands_db: Dict) -> float:
    """
    品牌信誉评分

    评分依据：
    - 一线品牌（禧玛诺、达瓦）：0.9-1.0
    - 二线品牌（光威、汉鼎）：0.6-0.8
    - 国产品牌（迪卡侬）：0.5-0.7
    - 未知品牌：0.5

    Args:
        equipment: 装备数据
        brands_db: 品牌数据库

    Returns:
        0.0-1.0的评分
    """
    brand = equipment.get('brand', '')
    brand_info = brands_db.get(brand, {})

    # 从数据库获取品牌信誉评分（0-100）
    reputation_score = brand_info.get('reputation_score', 50.0)

    # 归一化到0-1
    return reputation_score / 100.0
```

**品牌数据库示例**：
```json
{
  "禧玛诺": {"reputation_score": 95, "tier": "一线"},
  "达瓦": {"reputation_score": 93, "tier": "一线"},
  "光威": {"reputation_score": 70, "tier": "国产"},
  "迪卡侬": {"reputation_score": 65, "tier": "二线"}
}
```

### 4. 用户水平匹配评分（15%）

**算法**：装备适用水平与用户水平的匹配

```python
def calculate_user_level_score(equipment: Dict, user_level: str) -> float:
    """
    用户水平匹配评分

    规则：
    - 用户水平与装备适用水平匹配：1.0分
    - 装备高于用户水平1级：0.7分（可成长）
    - 装备低于用户水平1级：0.5分（不推荐）
    - 差距>1级：0.3分

    Args:
        equipment: 装备数据 {"user_level": ["新手", "进阶"]}
        user_level: 用户水平（新手/进阶/专业）

    Returns:
        0.0-1.0的评分
    """
    equipment_levels = equipment.get('specs', {}).get('user_level', ['通用'])

    level_map = {'新手': 1, '进阶': 2, '专业': 3, '通用': 2}
    user_level_num = level_map.get(user_level, 2)

    # 如果装备适用水平包含用户水平
    if user_level in equipment_levels or '通用' in equipment_levels:
        return 1.0

    # 计算水平差距
    equipment_avg_level = sum(level_map.get(lvl, 2) for lvl in equipment_levels) / len(equipment_levels)
    diff = abs(equipment_avg_level - user_level_num)

    if diff <= 0.5:
        return 1.0
    elif diff <= 1.0:
        return 0.7 if equipment_avg_level > user_level_num else 0.5
    else:
        return 0.3
```

## 🔧 综合评分计算

```python
class LureRecommender:
    """路亚装备推荐引擎"""

    def __init__(self, config: Dict = None):
        self.config = config or RECOMMENDATION_CONFIG
        self.brands_db = self._load_brands()

    def calculate_match_score(
        self,
        equipment: Dict,
        user_specs: Dict
    ) -> float:
        """
        计算装备与用户需求的综合匹配度

        Args:
            equipment: 装备数据
            user_specs: 用户规格要求
                {
                    "预算": 300,
                    "硬度": "ML",
                    "长度": 2.4,
                    "用户水平": "新手"
                }

        Returns:
            0-100的综合评分
        """
        weights = self.config['weights']

        # 1. 价格匹配评分
        price_score = calculate_price_score(
            equipment,
            user_specs.get('预算', 9999)
        )

        # 2. 规格匹配评分
        spec_score = calculate_spec_score(
            equipment,
            user_specs,
            self.config
        )

        # 3. 品牌信誉评分
        brand_score = calculate_brand_score(
            equipment,
            self.brands_db
        )

        # 4. 用户水平匹配评分
        level_score = calculate_user_level_score(
            equipment,
            user_specs.get('用户水平', '通用')
        )

        # 加权求和
        total_score = (
            price_score * weights['price_match'] +
            spec_score * weights['spec_match'] +
            brand_score * weights['brand_reputation'] +
            level_score * weights['user_level']
        )

        return total_score * 100  # 转换为0-100分


    def recommend(
        self,
        equipments: List[Dict],
        user_specs: Dict,
        top_k: int = 3
    ) -> List[Dict]:
        """
        推荐装备

        Args:
            equipments: 候选装备列表
            user_specs: 用户规格要求
            top_k: 返回Top K个推荐

        Returns:
            推荐装备列表（按评分降序）
        """
        # 计算每个装备的匹配度
        scored_equipments = []
        for equipment in equipments:
            score = self.calculate_match_score(equipment, user_specs)

            # 过滤低分装备（<50分）
            if score >= 50:
                scored_equipments.append({
                    **equipment,
                    'match_score': score
                })

        # 排序并返回Top K
        scored_equipments.sort(key=lambda x: x['match_score'], reverse=True)
        return scored_equipments[:top_k]
```

## 🎁 装备组合推荐

### 套装推荐算法

```python
def recommend_package(
    self,
    budget: float,
    user_level: str = "新手",
    category: str = "鲈鱼套装"
) -> Dict:
    """
    推荐装备套装

    策略：
    1. 预算分配：竿40% + 轮35% + 线25%
    2. 兼容性检查：竿轮匹配、线径匹配
    3. 性价比优化：总价接近预算但不超

    Args:
        budget: 总预算
        user_level: 用户水平
        category: 套装类型

    Returns:
        套装配置 {
            "rod": {...},
            "reel": {...},
            "line": {...},
            "total_price": 950,
            "compatibility_score": 0.95
        }
    """
    # 预算分配
    rod_budget = budget * 0.4
    reel_budget = budget * 0.35
    line_budget = budget * 0.25

    # 查询候选装备
    rod_candidates = self._fetch_equipment('鱼竿', {'预算': rod_budget, '用户水平': user_level})
    reel_candidates = self._fetch_equipment('渔轮', {'预算': reel_budget, '用户水平': user_level})
    line_candidates = self._fetch_equipment('鱼线', {'预算': line_budget, '用户水平': user_level})

    # 生成所有组合
    best_package = None
    best_score = 0

    for rod in rod_candidates[:5]:
        for reel in reel_candidates[:5]:
            for line in line_candidates[:5]:
                # 兼容性检查
                compatibility = self._check_compatibility(rod, reel, line)
                if compatibility < 0.7:
                    continue

                # 计算总价
                total_price = (
                    rod['price_min'] +
                    reel['price_min'] +
                    line['price_min']
                )

                # 预算控制
                if total_price > budget * 1.1:
                    continue

                # 计算套装评分
                package_score = self._calculate_package_score(
                    rod, reel, line, total_price, budget, compatibility
                )

                if package_score > best_score:
                    best_score = package_score
                    best_package = {
                        'rod': rod,
                        'reel': reel,
                        'line': line,
                        'total_price': total_price,
                        'compatibility_score': compatibility,
                        'package_score': package_score
                    }

    return best_package


def _check_compatibility(self, rod: Dict, reel: Dict, line: Dict) -> float:
    """
    检查装备兼容性

    规则：
    1. 竿的推荐线重 vs 线的拉力值
    2. 轮的线容量 vs 线的型号
    3. 竿的硬度 vs 轮的型号

    Returns:
        0.0-1.0的兼容性评分
    """
    scores = []

    # 1. 线重匹配
    rod_line_weight = rod['specs'].get('line_weight', '')  # "PE0.8-2.0"
    line_number = line['specs'].get('number', '')  # "1.0号"

    # 简单匹配（生产环境需要更复杂的解析）
    if line_number.replace('号', '') in rod_line_weight:
        scores.append(1.0)
    else:
        scores.append(0.5)

    # 2. 轮型号匹配
    reel_model = reel['specs'].get('model', '')  # "C2500"
    # ML/M竿适合2500-3000型轮
    rod_power = rod['specs'].get('power', '')
    if rod_power in ['ML', 'M'] and '2500' in reel_model or '3000' in reel_model:
        scores.append(1.0)
    else:
        scores.append(0.7)

    return sum(scores) / len(scores)
```

def test_price_scoring():
    """测试价格评分算法"""

    user_specs = {"预算": 300}

    # 测试1：价格刚好
    equipment1 = {"price_min": 300, "price_max": 350}
    score1 = calculate_price_score(equipment1, 300)
