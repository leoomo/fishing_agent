# 常见问题解答 v5.0.2

这里整理了用户在使用智能钓鱼助手过程中的常见问题和解答。

## 🎯 基础使用问题

### Q: 智能钓鱼助手是什么？
**A**: 智能钓鱼助手是基于人工智能的钓鱼辅助工具，提供：
- 实时天气分析和钓鱼建议
- 装备推荐和管理
- 钓鱼地点推荐
- 专业的钓鱼技巧指导

### Q: 如何开始使用？
**A**: 
1. **微信小程序**：搜索"智能钓鱼助手"或扫描二维码
2. **Web界面**：访问 http://your-domain.com
3. **详细指南**：查看 [快速开始](./getting-started.md)

### Q: 是否收费？
**A**: 
- **基础功能**：完全免费
- **高级功能**：提供付费增值服务
- **API调用**：有免费额度，超出后按量计费

## 🌤️ 天气与推荐问题

### Q: 天气数据准确吗？
**A**: 
- 数据来源：专业气象服务商（彩云天气）
- 更新频率：每小时更新实时数据
- 覆盖范围：全国所有城市和地区
- 准确度：专业级别，建议结合当地实际情况

### Q: 7因子评分是什么？
**A**: 系统综合考虑7个科学因素：
1. **温度** - 体感温度和水温
2. **天气** - 晴雨、云量状况
3. **风力** - 风力等级影响
4. **气压** - 气压变化影响
5. **湿度** - 空气湿度影响
6. **季节** - 季节性鱼情变化
7. **月相** - 月相对鱼情影响

### Q: 推荐的钓鱼时间可靠吗？
**A**: 
- 基于多年的钓鱼数据和气象分析
- 结合专业钓友的经验总结
- 建议作为参考，结合实际情况判断
- 关注当地的实时天气变化

## 📱 小程序使用问题

### Q: 小程序无法登录？
**A**: 
1. 检查微信版本是否为最新
2. 确认网络连接正常
3. 重新启动微信应用
4. 清除微信缓存后重试

### Q: 语音功能怎么用？
**A**: 
1. 点击输入框旁的麦克风图标
2. 授权麦克风权限
3. 清晰说出您的问题
4. 系统会自动转换为文字

### Q: 如何获取我的位置？
**A**: 
1. 确保手机GPS已开启
2. 授权微信获取位置权限
3. 系统会自动获取当前位置
4. 也可以手动输入地址
