# 故障排除指南 v5.0.2

本指南帮助您解决使用智能钓鱼助手时遇到的常见问题。

## 🔍 快速诊断

### 首先检查

1. **网络连接**
   - 确保设备已连接到互联网
   - 检查网络信号强度
   - 尝试刷新页面或重新打开应用

2. **服务状态**
   - 检查系统公告是否有维护通知
   - 访问 [系统状态页面](http://status.fishing-agent.com)
   - 确认服务正常运行

3. **版本更新**
   - 确保使用最新版本的应用
   - 小程序用户：下拉刷新检查更新
   - Web用户：清除浏览器缓存后重试

## 📱 微信小程序问题

### 无法打开小程序

**症状**：点击小程序无响应或加载失败

**解决方案**：
1. 检查微信版本是否为最新
2. 重启微信应用
3. 清除微信缓存
   - 设置 → 通用 → 存储空间 → 清理缓存
4. 卸载小程序后重新搜索进入

### 登录失败

**症状**：登录时提示错误或无法获取用户信息

**解决方案**：
1. 检查网络连接
2. 确认微信账号状态正常
3. 授权微信登录权限
4. 联系客服处理

### 消息发送失败

**症状**：输入消息后无法发送或长时间无响应

**解决方案**：
1. 检查网络连接稳定性
2. 重新输入消息内容
3. 避免发送过长的文本
4. 重启小程序重试

### 语音功能异常

**症状**：无法使用语音输入或识别错误

**解决方案**：
1. 检查麦克风权限
   - 微信 → 设置 → 隐私 → 麦克风
2. 确保环境安静，避免噪音干扰
3. 说话时距离手机适当距离
4. 使用文字输入作为备选方案

## 🌐 Web界面问题

### 页面加载缓慢

**症状**：页面打开很慢或部分内容无法显示

**解决方案**：
1. 检查网络速度
2. 清除浏览器缓存和Cookie
3. 尝试使用其他浏览器
4. 关闭不必要的浏览器插件

### 登录问题

**症状**：无法登录或登录后自动退出

**解决方案**：
1. 确认用户名和密码正确
2. 检查是否开启了Caps Lock
3. 清除浏览器缓存
4. 使用"忘记密码"功能重置密码

### 功能按钮无响应

**症状**：点击按钮无反应或页面无变化

**解决方案**：
1. 刷新页面（F5或Ctrl+R）
2. 检查浏览器JavaScript是否启用
3. 尝试使用无痕模式访问
4. 更新浏览器到最新版本

## 🔧 API调用问题

### 认证失败

**症状**：API返回401 Unauthorized错误

**解决方案**：
1. 检查Token是否过期
2. 重新获取访问令牌
3. 确认Token格式正确（Bearer + 空格 + Token）
4. 验证API密钥配置

```bash
# 验证Token格式
curl -H "Authorization: Bearer your_token_here" \
     http://localhost:8000/api/v1/user/profile
```

### 请求频率限制

**症状**：返回429 Too Many Requests错误

**解决方案**：
1. 降低请求频率
2. 实现请求间隔控制
3. 使用缓存机制减少重复请求
4. 考虑升级API套餐

### 数据格式错误

**症状**：返回400 Bad Request错误

**解决方案**：
1. 检查JSON格式是否正确
2. 确认必需字段都已提供
3. 验证数据类型是否匹配
4. 查看API文档确认接口规范

```python
# 正确的请求格式示例
import json
import requests

data = {
    "query": "明天北京钓鱼怎么样？",
    "model_provider": "zhipu",
    "user_id": 123
}

headers = {
    "Authorization": "Bearer your_token",
    "Content-Type": "application/json"
}

response = requests.post(url, json=data, headers=headers)
```

## 🤖 智能回复问题

### 回复不准确

**症状**：系统回答与实际天气或情况不符

**解决方案**：
1. 提供更具体的时间和地点信息
2. 明确您的钓鱼偏好和目标
3. 分步骤提出复杂问题
4. 反馈错误信息帮助系统改进

### 无法理解问题

**症状**：系统回复无法理解或答非所问

**解决方案**：
1. 使用简洁明了的语言
2. 避免使用专业术语
3. 分解复杂问题为简单问题
4. 提供更多上下文信息

**好的提问示例**：
```
✅ 明天早上6点到9点，北京朝阳区适合钓什么鱼？
✅ 我是新手，预算500元，想买路亚竿，求推荐
✅ 杭州西湖今天天气如何？能钓鱼吗？
```

**需要改进的提问**：
```
❌ 钓鱼
❌ 推荐个竿
❌ 北京怎么样？
```

## 📸 OCR功能问题

### 识别失败

**症状**：上传图片后无法识别或返回错误

**解决方案**：
1. 确保图片清晰可读
2. 避免模糊、反光或阴影
3. 确保文字方向正确
4. 使用支持的图片格式（JPG、PNG）

### 识别结果不准确

**症状**：识别的文字内容错误或不完整

**解决方案**：
1. 提高图片分辨率
2. 确保光线充足均匀
3. 避免手写或艺术字体
4. 裁剪图片到相关区域

```python
# 图片预处理建议
from PIL import Image, ImageEnhance

# 增强对比度
img = Image.open("equipment.jpg")
enhancer = ImageEnhance.Contrast(img)
enhanced_img = enhancer.enhance(2.0)
enhanced_img.save("enhanced_equipment.jpg")
```

## 🔄 数据同步问题

### 信息不同步

**症状**：不同设备上的数据不一致

**解决方案**：
1. 检查账号登录状态
2. 手动刷新数据
3. 确认网络连接稳定
4. 联系客服同步数据

### 历史记录丢失

**症状**：之前的对话记录或数据消失

**解决方案**：
1. 检查是否登录了正确账号
2. 查看是否有其他设备登录
3. 确认未清除应用数据
4. 联系客服恢复数据
