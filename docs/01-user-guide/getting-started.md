## 🎯 第一个钓鱼推荐

### 方式一：使用微信小程序（推荐新手）

1. **打开微信小程序**
   - 在微信中搜索"智能钓鱼助手"
   - 或扫描二维码进入小程序

2. **开始对话**
   ```
   用户：明天北京钓鱼怎么样？
   助手：根据天气预报，明天北京晴朗，温度15-25℃，风力2-3级，气压稳定，非常适合钓鱼！推荐早6-9点或晚5-7点作钓。
   ```

### 方式二：使用 Web 界面

1. **访问管理界面**
   - 打开浏览器访问：http://your-domain.com
   - 点击"开始使用"

2. **输入钓鱼问题**
   - 在聊天框输入您的问题
   - 点击发送或按回车键

### 方式三：使用 API 接口（适合开发者）

```bash
# 1. 获取访问令牌
curl -X POST "http://localhost:8000/api/v1/auth/wechat/login" \
  -H "Content-Type: application/json" \
  -d '{"code": "your_wechat_code"}'

# 2. 使用令牌获取钓鱼推荐
curl -X POST "http://localhost:8000/api/v1/fishing/chat" \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "明天上海哪里适合钓鱼？",
    "model_provider": "zhipu"
  }'
```

## 🔧 功能特色

### 🌟 7因子科学评分
系统会综合考虑以下7个因素给出科学的钓鱼建议：

1. **温度** - 体感温度和水温对鱼情的影响
2. **天气** - 晴雨、云量对鱼类活动的影响  
3. **风力** - 风力等级对水层和溶氧量的影响
4. **气压** - 气压变化对鱼类觅食的影响
5. **湿度** - 空气湿度对舒适度的影响
6. **季节** - 不同季节鱼类习性变化
7. **月相** - 月相对潮汐和鱼类活动的影响

## ⚠️ 注意事项

### 天气提醒
- 系统建议仅供参考，请结合实际情况判断
- 恶劣天气请勿作钓，确保安全第一
- 关注当地天气预报，及时调整计划

### 法律法规
- 遵守当地钓鱼规定和禁渔期
- 保护环境，文明钓鱼
- 注意钓鱼区域的安全警示

### 数据准确性
- 天气数据来源于专业气象服务
- 建议结合当地实际情况
- 如有疑问可人工核实关键信息
